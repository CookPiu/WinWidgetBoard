# WinWidgetBoard UI、视觉与动效规范

文档状态：已批准基线

版本：0.2

日期：2026-08-18

> 本文是当前轻量核心版的 UI 权威规范，只覆盖任务栏入口、WorkspacePanel、基础布局、本地便签、天气与手动位置设置。计时器、待办、剪贴板、日历、插件、账号和云同步不是当前 UI 扩展目标。实现事实以本文和现有资源共同约束；出现偏差时，应先判断是实现回归还是确有必要修改规范，禁止直接复制局部常量形成第二套视觉系统。

## 1. 设计方向

产品视觉语言定为“静谧画布”：

- **内容优先**：边框、工具栏和状态提示不能挤占主要内容；
- **紧凑但不局促**：遵循 4 DIP 节奏，控件命中区不因视觉收缩而失去可用性；
- **一层主结构**：面板承载环境质感，卡片承载内容，避免卡片内继续堆叠有底色、有边框的容器；
- **系统原生**：优先使用 WinUI、Windows 语义色、系统字体、高对比度和减少动态效果设置；
- **直接稳定**：高频操作即时响应，拖动和缩放保持对象身份、位置与尺寸独立；
- **克制动效**：动效只解释状态、空间关系或操作反馈，不用于装饰和拖延。

所有新 UI 必须能回答三个问题：

1. 它是否让核心任务更快或更清楚？
2. 它是否可以复用现有 token、样式或组件结构？
3. 如果移除它的边框、底板或动效，信息是否仍然清晰？

无法回答时，不应加入界面。

## 3. 信息架构

```text
任务栏入口（嵌入任务栏条带的信息条）
├─ 信息文本（日期与时间；天气模式待定）
├─ 右键菜单（显示内容、入口位置、左对齐回退）
└─ WorkspacePanel
   ├─ 单行头部
   │  ├─ 标题、日期和必要状态
   │  ├─ 便签搜索
   │  └─ 全局操作
   ├─ 临时结果层（仅在搜索或明确上下文中出现）
   ├─ 卡片网格
   │  ├─ 本地便签
   │  ├─ 天气
   │  └─ 已延期占位卡（只维护，不扩展）
   └─ 设置浮层
      └─ 天气位置（地点搜索 → 候选列表 → 只读经纬度）
```

强制约束：

- 搜索框不得独占一行；
- 单组按钮不得独占一行；
- 低频操作不得长期占据卡片正文空间；
- 状态提示只在加载、过期、离线、错误或空状态时出现；
- 临时结果层可以换行出现，但必须按需显示并可立即收起；
- 新入口、新设置分类和新卡片类型必须先通过产品范围决策。

### 3.1 任务栏入口

入口是嵌入任务栏条带的一枚胶囊，不再是工作区内的方形按钮。

#### 尺度与结构

| 项目 | 值 |
| --- | --- |
| 高度 | 条带高度减去上下各 4 DIP，夹在 32～40 DIP |
| 宽度 | 随内容自适应，夹在 96～280 DIP，按 4 DIP 量化 |
| 圆角 | 短边的一半，形成胶囊 |
| 内边距 | 左右各 12 DIP |
| 指示器 | 宽 4 DIP，与文本间距 8 DIP，静息高 4 DIP，面板打开时 16 DIP |
| 天气图标 | 18 DIP 见方，与文本间距 8 DIP，仅天气模式出现 |
| 字号 | 14 DIP，`Segoe UI` Semibold |

内容自左向右为：12 DIP 内边距 → 指示器 → 8 DIP 间距 →〔天气图标 → 8 DIP 间距〕→ 文本 → 12 DIP 内边距。
指示器**始终占位**，只有高度和不透明度变化，因此状态切换不会引起重排；天气图标只在天气模式下
占位，切换显示内容本来就会重新测量宽度。

天气模式显示**图标 + 温度**，不显示地区：地区是用户自己设定的，每分钟重复一遍只是在花掉入口的宽度。
图标即当前天气状况的表达，因此入口不含任何需要翻译的措辞。

图标由入口自己用圆、圆角矩形和一个多边形组合绘制，不使用图标字体——入口本来就在合成自己的
预乘位图，引入字体只会为这么小的一组图形增加一项可用性依赖。图标取值与 `conditionIconId`
一一对应（见 [API 契约](07-api-contracts.md)），未收录的标记画中性圆环，不猜相近天气。
图标使用与文本相同的颜色和不透明度：入口是系统表面，单色标记在任何任务栏底色上都保持可读，
也不会和入口既有的颜色映射脱节。彩色插画留给面板内的卡片。

#### 颜色映射

入口是分层窗口，没有 XAML，也就没有 `ThemeResource`。因此面板的调色板在这里被映射成
最小且可核对的一组，**不允许**在此之外再引入颜色：

| 角色 | 来源 |
| --- | --- |
| 强调色（指示器、打开态染色） | `GetSysColor(COLOR_HIGHLIGHT)` |
| 中性底色 | 纯白或纯黑，由 `HKCU\...\Themes\Personalize\SystemUsesLightTheme` 决定（任务栏跟随的是这个值，不是应用主题） |
| 高对比度 | 全部改用 `GetSysColor`，取消一切半透明，并恢复 1 DIP 系统边界 |

底色不透明度（深色条带 / 浅色条带）：静息 `0.10` / `0.07`，悬停 `0.20` / `0.15`，
按下 `0.26` / `0.21`，面板打开 `0.24` / `0.20`。浅色一侧的步长更大，因为深色叠加在浅色上
每单位 alpha 的感知对比明显更低。打开态在底色中混入 `0.85` 的强调色。

#### 质感

- 底色带自上而下 `0.22` 幅度的轻微渐变，只用于制造厚度，不作为装饰性渐变；
- 深色条带在胶囊上半沿加一道 1 DIP 的白色微光（`0.16`），到中线淡出，表达受光边缘；
- 除高对比度外不画描边——第 6.3 节的「不给每层容器描边」同样适用于入口。

#### 状态与动效

| 状态 | 表达 |
| --- | --- |
| 悬停 | 底色不透明度提高 |
| 按下 | 底色继续提高，胶囊与指示器整体缩放至 `0.97` |
| 面板打开 | 底色染上强调色，指示器由圆点**长成**竖条 |

- 状态不得只靠颜色区分：打开态的判据是指示器的**形状变化**；
- 三个通道各自是一条临界阻尼弹簧，角频率与面板开合动效相同（`15.4919`），
  使入口点亮与面板展开在同一条曲线上收敛，而不是两个可见的不同速度；
- 动画定时器只在状态迁移期间存在，收敛即销毁：静息入口没有任何定时器唤醒；
- 反向操作从当前显示值继续；
- `SPI_GETCLIENTAREAANIMATION` 为 `FALSE` 时改为约 150 ms 的淡入淡出，并因此自动去掉缩放。

### 3.2 天气卡片插画

天气卡片在内容之后叠一层随天气状况变化的平面插画，用来让卡片在一屏之内可被快速辨认，
而不是靠读温度数字。

- 构成是「一层天空底色 + 一到三个平面图形」，图形放在卡片**右下角的空白区**并溢出圆角；
  右上角归位置标签所有，把图形放到那里只会读成一团污渍；
- 底色不透明度 `0.18`～`0.26`，图形 `0.10`～`0.22`，正文始终是卡片上对比度最高的元素；
- 插画裁剪到卡片自身的圆角，不接收指针输入，也不带自动化名称——同样的事实已经由卡片文字表述；
- 一次只实例化选中的那一个背景（`WeatherBackdropTemplateSelector`），因为网格会在拖动时
  实例化和回收卡片表面；
- 毛毛雨与雨共用一张插画：卡片大小的图形本来就画不出两者的区别；
- 未收录的天气标记不画插画，而不是画一个相近的天气。

#### 约束

- 合成使用预乘 BGRA 位图与 `UpdateLayeredWindow`，圆角与文字都带真实逐像素 alpha；
  不使用色键透明，也不设置窗口区域——两者都会把抗锯齿边缘削回一位透明度；
- 文本使用灰度抗锯齿。分层窗口上的 ClearType 子像素渲染会出现彩色边缘；
- 宽度必须有滞回，跨过 8 DIP 才重排，避免时间文本变化导致入口抖动；
- 入口只在**胶囊本体**内接收输入，圆角外侧与其余区域穿透；
- 内容变化只重绘，不重排，除非宽度真的跨过滞回带。

### 3.3 天气位置设置

对话框的顺序就是用户的思路：**搜索地名 → 从候选中选择 → 保存**。

- 搜索框在提交时才发起请求，不做按键即搜；请求进行中显示不确定进度条；
- 候选行显示「名称」与其下一行的「一级行政区 · 国家」，用来区分同名地点；
  城市州（名称与行政区、国家相同）只显示一次，不重复自己的名字；
- 经纬度**只读展示**，标题写明「将保存的经纬度」：它是真正会发给天气服务的东西，
  藏起来会让这件事不可见，可编辑又会把用户重新推回抄坐标；
- 「没有匹配的地点」与「搜索暂时不可用」是两条不同的状态文案，不能合并；
- 位置名称仍可编辑：搜索结果给出的名称未必是用户想在卡片上看到的写法。

## 4. 面板与响应式布局

### 4.1 面板几何

- 面板宽度目标为工作区宽度的 `46%`，逻辑宽度限制在 `680～960 DIP`；
- 面板高度目标为工作区高度的 `90%`，逻辑最小高度为 `560 DIP`；
- 面板距工作区边缘 `10 DIP`；
- 优先从 LauncherHost 所在角落展开；入口几何不可用时使用工作区左下角；
- 所有尺寸按当前显示器 DPI 换算，最终矩形不得越出工作区；
- 不以全屏或固定像素代替响应式计算。

### 4.2 卡片网格

| 项目 | 当前基线 |
| --- | ---: |
| 列数 | `2 / 4 / 6` |
| 列间距 | `8 DIP` |
| 行间距 | `8 DIP` |
| 基础行高 | `160 DIP` |
| 内容对齐 | 顶部开始 |
| 内容滚动 | 面板主体统一滚动 |

列数由可用宽度和已有布局合同决定。卡片跨度只能使用布局模型支持的值，不得通过负边距、绝对坐标或局部缩放伪造尺寸。

### 4.3 稳定身份不变量

布局编辑必须同时保持以下不变量：

- 每个卡片实例在同一编辑轮次内只有一个稳定 `InstanceId`；
- placement 或 order 变化只原地更新稳定的 `CardSurfaceItem`，不能为了刷新位置重排数据源对象；
- 只有成员增删才允许重建或重新绑定 ItemsRepeater 数据源；
- 拖动和缩放必须从当前已实现的 repeater 元素解析目标，不能依赖可能过期的根元素 `Tag`；
- 一个卡片的尺寸步进只基于该卡片当前尺寸，不得继承上一个操作对象的尺寸；
- 拖动、缩放、撤销和重做不得产生重复卡片或让其他卡片发生位移。

凡修改 `CardGridLayout`、`CardLayoutSurfaceViewModel`、ItemsRepeater 绑定、拖动或缩放代码，必须执行“同一编辑轮次下跨卡片拖动 + 缩放”的真实组合回归。

## 5. 密度与空间

### 5.1 4 DIP 节奏

| Token | 数值 | 典型用途 |
| --- | ---: | --- |
| `WwbSpace1` | `4` | 图标与标签、紧密工具组 |
| `WwbSpace2` | `8` | 网格间距、卡片内部行距 |
| `WwbSpace3` | `12` | 紧凑卡片内边距、主要区域间距 |
| `WwbSpace4` | `16` | 较大内容分组 |
| `WwbSpace5` | `20` | 少量强调留白 |
| `WwbSpace6` | `24` | 页面级分隔 |
| `WwbSpace8` | `32` | 控件命中基线或极少数大间距 |

已批准的组合值：

- 头部内边距：`12,8`；
- 主体内边距：`12,6,12,12`；
- 标准卡片内边距：`14`；
- 紧凑卡片内边距：`12`；
- 次级表面内边距：`8`；
- 工具栏内边距：`4`。

新增间距优先从表中选择。不得在同一组件中混用大量 `5/7/9/11/13/15` 等近似值制造不可维护的“视觉微调”。

### 5.2 空间预算

- 头部只保留一行常驻结构，标题区最大宽度受限，搜索使用剩余空间，全局按钮靠右；
- 卡片头部只容纳标题和最常用操作；
- 卡片正文是首要空间，辅助说明、重复标签和装饰性图标不得压缩正文；
- 便签默认态只常驻标题、正文、新建和“更多”；
- Markdown、复制、删除、恢复、重试等操作按模式或状态出现；
- 无内容时使用一句简短提示和一个下一步，不使用多层空状态卡。

## 6. 材质、颜色、边框与圆角

### 6.1 层级

1. 顶层面板使用 Desktop Acrylic 承载环境色；
2. 面板顶部可叠加系统强调色微光，当前不透明度为 `0.06`；
3. 卡片使用较实的系统语义表面，保证文字稳定可读；
4. 浮层可使用 In-App Acrylic，但不能与多层半透明卡片叠加；
5. ThemeShadow 只表达浮起或层级，不作为常驻分隔线。

### 6.2 颜色

- 只使用 `ThemeResource` 和 Windows 语义色表达文字、表面、强调、危险及禁用状态；
- 不为普通正文、图标或按钮写死 RGB/十六进制颜色；
- **唯一例外是天气卡片的插画配色**：没有任何 Windows 语义色的含义是「阴天的天空」。
  该配色集中定义在 `WorkspaceVisualStyles.xaml` 的主题字典里，键名一律以 `WwbWeather` 开头，
  页面只引用键、永远不自己写颜色；高对比度把其中每一个都改为 `Transparent`。
  `UT-UI-002` 会断言这两条：字面颜色只能出现在 `WwbWeather*` 画刷上，且必须在高对比度里被清零；
- 强调色只用于焦点、选中、主要动作和少量环境微光；
- 危险色只用于真实破坏性动作或失败状态；
- 不能只靠颜色传达状态，必须同时有文字、图标、形状或自动化名称。

### 6.3 边框

- 普通主题的面板、头部、卡片和次级表面默认边框为 `0`；
- 高对比度主题恢复系统 `1 DIP` 边界；
- 浮层边框为 `1 DIP`；
- 禁止为了“精致感”给每一层容器都加描边；
- 分组优先使用间距、字号、字重、底色差和对齐，不优先使用线框。

### 6.4 圆角

| Token | 数值 | 用途 |
| --- | ---: | --- |
| `WwbPanelCornerRadius` | `16` | 顶层面板 |
| `WwbCardCornerRadius` | `12` | 卡片 |
| `WwbControlCornerRadius` | `7` | 输入、工具条、次级表面 |
| `WwbSmallCornerRadius` | `6` | 小按钮、拖动柄、骨架块 |

同一层级不得随意混用不同圆角。

## 7. 字体与控件尺度

使用 Windows 默认 UI 字体，不为普通界面引入品牌字体。

| 语义 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 面板标题 | `16 / 22` | SemiBold |
| 面板元信息 | `11 / 16` | Regular |
| 面板上下文 | `10 / 14` | Regular |
| 卡片标题 | `13 / 18` | SemiBold |
| 卡片正文 | `12 / 17` | Regular |
| 卡片说明 | `11 / 16` | Regular |
| 天气温度 | `28 / 32` | SemiBold |
| 便签标题输入 | `14` | SemiBold |
| 便签正文输入 | `13` | Regular |

控件基线：

- 头部图标按钮：`32 × 32 DIP`，图标光学尺寸约 `14 DIP`；
- 卡片图标按钮：`28 × 28 DIP`；
- 卡片常规动作：最小高度 `32 DIP`；
- 便签低频工具：最小高度 `28 DIP`；
- 搜索框：最小高度 `32 DIP`，字号 `13`；
- 拖动柄：最小命中区 `32 × 32 DIP`。

文字层级最多使用三档同时出现。不能通过不断放大标题来制造层级，应先减少周围噪声。

## 8. 组件结构模板

模板规定结构和职责，不复制一套脱离资源字典的硬编码样式。

### 8.1 面板壳层

```text
PanelRoot (Desktop Acrylic + WwbPanelRootStyle)
├─ AccentWash（高对比度自动禁用）
├─ HeaderSurface (WwbHeaderSurfaceStyle)
│  └─ Title/Meta | Search | GlobalCommands
├─ TransientSurface（默认 Collapsed）
└─ ScrollViewer
   └─ ItemsRepeater + CardGridLayout
```

### 8.2 卡片

```text
CardSurface (WwbCardSurfaceStyle, MinHeight=160)
└─ Grid (RowSpacing=8)
   ├─ Header
   │  ├─ Title
   │  └─ PrimaryAction / Overflow
   ├─ PrimaryContent
   └─ ConditionalStatusOrEditControls
```

规则：

- 卡片根元素使用统一表面样式、圆角和阴影策略；
- 主内容只保留一个主要视觉焦点；
- 常用动作直接显示，低频动作进入 Overflow；
- 状态区与编辑工具只在需要时进入视觉树；
- 不在卡片内部再套一个“完整小卡片”；
- 输入控件有明确字段语义时可保留控件边界；便签正文等沉浸式编辑区优先无嵌套描边；
- 当前产品范围不允许以此模板为由扩展新卡片类型。

### 8.3 运行状态

| 状态 | 表现 | 允许操作 |
| --- | --- | --- |
| Loading | 紧凑骨架或短提示 | 关闭、取消（若支持） |
| Ready | 不显示额外状态层 | 正常操作 |
| Stale | 保留最近内容并给出更新时间 | 手动重试 |
| Offline | 保留缓存内容并说明离线 | 手动重试 |
| Error | 简明原因和可执行下一步 | 重试或打开相关设置 |
| Empty | 一句说明和一个主要动作 | 创建或配置 |

状态层不得覆盖已有可用内容，也不得用 Ready 标签长期占位。

## 9. 动效规范

### 9.1 是否需要动效

| 场景 | 处理 |
| --- | --- |
| 高频点击、输入、拖动、缩放 | 即时反馈，不增加等待 |
| 面板出现/退出 | 解释与入口的空间关系 |
| 浮层、搜索结果、预览切换 | 短透明度和轻缩放过渡 |
| 布局重排 | 仅在不破坏 1:1 拖动和稳定身份时采用 |
| 长时间装饰、循环呼吸、颜色流动 | 禁止 |

### 9.2 参数与实现

- 渐进浮层进入：`180ms`，退出：`125ms`；
- 减少动态效果模式：`150ms` 淡化，不做位移和缩放；
- 浮层进入缩放从 `0.985` 到 `1`，退出目标不低于 `0.99`；
- 拖动浮起比例为 `1.01`，只辅助表达抓取，不改变布局测量；
- 按压反馈可使用 `0.96～0.98`，释放后立即恢复；
- 进入使用 ease-out，屏幕内移动使用 ease-in-out，颜色和悬停使用短 ease；不使用让操作初段迟钝的 ease-in；
- 优先只动画 `Opacity`、`Scale`、`Translation` 等合成层属性；
- 不动画 `Width`、`Height`、`Margin` 等会持续触发布局的属性；
- 不使用 `transition all`、无因弹跳、长弹簧尾巴或无法中断的故事板；
- 反向操作必须从当前显示值继续，不能先跳回起点。

任何新增动效都要在 UI 变更模板中填写“目的、频率、时长、属性、可中断性、减少动态效果降级”。没有明确目的时选择不动画。

## 10. 输入、焦点与无障碍

- 所有图标按钮必须有本地化工具提示、可读自动化名称和稳定唯一的 `AutomationId`；
- Tab 顺序遵循视觉顺序，浮层打开后焦点进入浮层，关闭后返回触发控件；
- `Esc` 优先取消当前拖动或编辑，其次关闭浮层，最后关闭面板；
- 拖动不能从 TextBox、Button、ScrollViewer 等交互控件误触发；
- 不能只提供拖动路径；布局编辑要保留可发现的缩放、撤销和重做；
- 高对比度下使用系统色和 `1 DIP` 必要边界；
- 减少动态效果下保留状态变化和焦点反馈，只移除空间位移与缩放；
- 200% DPI 等缩放下，逻辑命中尺寸不变，不能用物理像素硬编码；
- 截断文本必须有可访问全量内容或替代说明。

## 11. UI 变更流程

每次可见 UI 变更开工前：

1. 阅读本文，并复制或引用 `docs/templates/ui-change-template.md` 作为工作检查表；
2. 固定参考环境：主题、DPI、窗口尺寸、语言、数据状态和基线提交；
3. 保存修改前截图或可复现描述；
4. 使用下表评审，不接受只有“更好看”的结论；
5. 优先修改集中 token、Style 或组件结构，再考虑页面局部值；
6. 按风险等级执行静态、构建和真实桌面流程；
7. 保存修改后同条件截图及交互证据。

UI 评审必须使用：

| Before | After | Why |
| --- | --- | --- |
| 当前可观察问题和证据 | 具体变化及数值 | 对内容空间、层级、可用性或一致性的影响 |

普通修复默认不提交一份已填写模板副本；设计决策、截图和验证结果可记录在任务、PR 或提交说明中。只有跨多轮、高风险或需要长期追踪的 UI 改造才单独保存记录。

## 12. 验收门禁

### 12.1 静态门禁

- 没有无理由的新颜色、间距、字号、圆角或阴影；
- 没有搜索、按钮或状态独占常驻整行；
- 没有新增嵌套边框和重复底板；
- 所有图标操作具备工具提示、自动化名称和唯一 AutomationId；
- XAML、资源键和本地化引用可解析；
- `git diff --check` 通过。

### 12.2 L2 真实桌面门禁

UI、布局、动效或进程交互变更至少验证：

- 受影响可执行文件的 Release 构建或 smoke；
- 一条直接覆盖本次风险的真实鼠标或键盘流程；
- 与参考条件一致的修改后截图；
- 常用操作无新增等待和误触；
- 涉及布局编辑时，跨卡片拖动 + 缩放组合不串尺寸、不丢位置、不复制卡片；
- 涉及动效时，快速反向操作不中断逻辑状态，减少动态效果有合理降级；
- 涉及主题与边界时，至少检查普通主题，并按风险决定是否增加深色、高对比度或 DPI 检查。

单元测试、进程正常退出或静态截图均不能单独替代真实交互证据。

## 13. 禁止项

- 注入或修改 Explorer；
- 以更多常驻工具栏换取“功能完整”；
- 把搜索、按钮组或说明文字拆成独立常驻行；
- 为每层容器增加背景、边框、圆角和阴影；
- 用任意硬编码颜色绕过系统主题；
- 用缩小命中区换取表面紧凑；
- 在拖动中加入破坏指针 1:1 投影的通用重排动画；
- 用新动画掩盖状态跳变、身份错配或数据刷新问题；
- 扩展延期卡片、插件、账号、云同步或复杂设置体系；
- 未固定参考环境就宣称视觉或性能改善。
