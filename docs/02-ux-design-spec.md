# WinWidgetBoard UX、视觉与动效规范

文档状态：已批准基线
版本：0.1
日期：2026-08-06

> 当前适用范围：入口、面板、基础布局、便签和天气。待办、剪贴板及其他卡片章节仅保留为历史设计参考，不是当前实现或验收项。完整显示器、偏好和无障碍矩阵只在发布候选阶段执行。

## 1. 设计目标

界面应让用户感到：

- **平静**：没有资讯流、广告、闪烁和无意义提醒；
- **直接**：按下立即响应，拖动与指针保持同步；
- **连续**：打开、关闭、切换和拖拽没有跳帧或突然重置；
- **可预测**：面板始终从入口出现并回到入口；
- **可掌控**：任何网络、账号、剪贴板和插件权限都能看见并关闭；
- **熟悉但不复刻**：遵循 Windows 操作习惯，同时使用更克制的空间和动效。

Apple Design 技能在本项目中的具体转化是：

1. response：反馈发生在 pointer-down；
2. direct manipulation：拖动 1:1 跟随并保留抓取偏移；
3. interruptibility：动画从当前显示值继续，可随时反向；
4. spatial consistency：面板从入口锚定，退出沿相同路径；
5. restraint：弹出面板不使用无因回弹；
6. accessibility：减少动态效果仍保留状态反馈。

## 3. 任务栏入口

### 3.1 视觉

- 默认视觉尺寸：36×36 逻辑像素；
- 最小命中尺寸：32×32；
- 图标光学尺寸：18～20；
- 圆角：8；
- 不绘制独立大面积背景，优先融入任务栏；
- 静止状态不使用持续阴影、光晕或颜色循环；
- 徽标最大占图标宽度约 40%，不可遮盖主体识别。

### 3.2 状态

| 状态 | 表现 |
| --- | --- |
| Rest | 透明或轻微系统填充 |
| Hover | 轻微提高填充对比度 |
| Pressed | `scale 0.96～0.98`，立即响应 |
| PanelOpen | 保持选中填充，不重复脉冲 |
| Attention | 静态徽标；仅严重情况允许一次短动效 |
| Disabled | 降低不透明度并提供原因 |
| Conflict | 隐藏入口，在托盘或设置提示重新定位 |

### 3.3 交互

- pointer-down：立即进入 Pressed；
- pointer-up inside：提交开关；
- pointer-up outside：取消；
- 右键：打开原生风格上下文菜单；
- hover：只显示短工具提示，不打开面板；
- 键盘快捷键：与鼠标开关完全等价。

## 4. 面板几何与层级

### 4.1 默认几何

```text
width  = clamp(680, workAreaWidth * 0.46, 960)
height = clamp(560, workAreaHeight * 0.90, workAreaHeight - 16)
edgeGap = 8～12
```

在 1920×1080、100% 缩放下，建议初始宽度约 840～900，高度约 920～960；实际值以工作区而非物理屏幕为准。

### 4.2 层级

1. 桌面和普通应用；
2. 工作台面板；
3. 卡片详情或轻量菜单；
4. 文件选择器、账号授权等模态窗口；
5. Windows 安全桌面与系统关键 UI。

面板是并行工作表面，不是强制用户完成任务的模态框，因此默认不使用全屏遮罩。可用阴影、边缘对比和材质区分层级。

### 4.3 窗口行为

- 入口所在显示器决定面板显示器；
- 不在 Alt+Tab 和任务栏生成普通应用按钮；
- 面板外点击关闭，但模态作用域、拖拽、编辑和输入期间暂停失焦关闭；
- 面板关闭时记住滚动位置；超过可配置时间后可恢复顶部；
- 显示器断开时先安全关闭，再迁移到主显示器。

## 5. 面板布局

### 5.1 间距系统

基础单位为 4 逻辑像素：

| Token | 值 | 用途 |
| --- | ---: | --- |
| `space-1` | 4 | 图标内部微间距 |
| `space-2` | 8 | 紧凑控件 |
| `space-3` | 12 | 卡片内部相邻项 |
| `space-4` | 16 | 卡片内边距、网格间距 |
| `space-5` | 20 | 标题区 |
| `space-6` | 24 | 大区块分隔 |
| `space-8` | 32 | 空状态与大标题 |

不得随意出现 13、17、19 等不可解释间距。

### 5.2 网格

- 小宽度：2 列；
- 标准宽度：4 列；
- 超过 900 逻辑像素：可使用 6 列；
- 列间距：12～16；
- 行高单位建议 112～128；
- 布局数据保存跨度和顺序，不保存实际像素。

### 5.3 卡片结构

```text
Card
├─ Header（可选）
│  ├─ Icon
│  ├─ Title
│  ├─ Status
│  └─ More
├─ Primary content
├─ Secondary information
└─ Actions（按需）
```

小卡片不强制显示标题栏；图标和内容本身足够明确时可省略。

| 快速便签 | L | M/L/XL |
| 计时器 | M | S/M/L |
| 待办 | L | M/L/XL |
| 剪贴板 | W | M/W/L/XL |
| 月历 | L | L/XL |

| 系统监控摘要 | W | S/M/W/L/XL |

调整尺寸时优先改变信息密度，不简单放大字号或留白。

## 7. 编辑模式

### 7.1 进入

点击标题区“编辑”后：

- 卡片显示拖动柄；
- 支持尺寸的卡片显示缩放控制；
- 显示移除按钮；
- 标题区切换为“完成、撤销、重做、恢复默认”；
- 普通卡片主操作暂时停用，避免与拖动冲突。

### 7.2 拖动

- pointer-down 后保留抓取点相对偏移；
- 移动超过 8～10 像素才承诺为拖动；
- 拖动卡片提高层级，缩放至 1.01～1.02，阴影增强；
- 其他卡片从当前显示位置弹簧移动到预览位置；
- 网格边缘使用渐进阻力，不能瞬间硬停；
- 快速释放时可根据速度投影落点，但最终必须落在最近合法网格；
- `Esc` 恢复拖动前位置；
- 拖动过程中保持 1:1 跟随，不用延迟动画追赶指针。

### 7.3 缩放

- 首选尺寸菜单或清晰缩放柄；
- 缩放只在卡片声明的尺寸集合中切换；
- 预览其他卡片让位；
- 不允许出现内容裁剪后无法操作的中间尺寸。

### 7.4 撤销

每次移动、缩放、添加、删除形成一个布局命令。撤销和重做应保持焦点在受影响卡片，并向屏幕阅读器播报结果。

## 8. 动效系统

### 8.1 原则

- 动效解释状态变化，不作为装饰；
- 开始于当前屏幕值，不从逻辑目标重置；
- 交互期间不锁定输入；
- 进入和退出路径对称；
- 非手势事件默认无弹跳；
- 卡片每秒数据更新不触发大面积位移动画。

### 8.2 动效 Token

| Token | 建议 | 用途 |
| --- | --- | --- |
| `motion-instant` | 70～100ms ease-out | 按压、悬停 |
| `motion-fast` | 140～180ms | 颜色、淡入、轻菜单 |
| `motion-panel` | 临界阻尼，response 0.28～0.34s | 面板开关 |
| `motion-layout` | 临界阻尼，response 0.30～0.40s | 卡片让位 |
| `motion-drag-release` | damping 0.82～0.92，response 0.30～0.40s | 有速度的拖动释放 |
| `motion-reduced` | 120～180ms opacity | 减少动态效果 |

实现框架若不直接暴露 damping/response，应通过帧分析匹配视觉行为，不得把 response 当固定 duration。

### 8.3 面板打开

初始状态来自入口所在角：

- 轻微位移：X -8～-16、Y 8～20，方向按屏幕边缘调整；
- scale：0.96～0.985；
- opacity：0～1；
- 材质可从较实到目标透明度；
- transform origin 对准入口。

面板内容不可逐卡片长时间交错进入。最多对首屏卡片使用 20～30ms 的短级联，总延迟不得影响操作。

### 8.4 面板关闭

- 沿打开路径反向；
- 第二次触发时读取当前视觉值立即反向；
- 关闭期间仍允许用户再次打开；
- 完全不可见后才释放或降级内容。

### 8.5 数值与图表

- 高频数字优先直接替换或短交叉淡化；
- 禁止每秒对每个数字做滚轮动画；
- 图表只有在卡片可见时更新画面；
- 状态阈值颜色变化使用 140～180ms；
- 严重告警可使用一次短强调，不循环呼吸。

## 9. 材质、颜色和深度

### 9.1 材质

- 面板可使用 Mica 或 Acrylic，具体由可用 API 和性能测试决定；
- 卡片优先使用半透明或实色层，不在透明面板上叠加高强度透明卡片；
- 减少透明度开启时使用接近实色背景和清晰边界；
- 大面板材质应比小浮层更厚重；
- 编辑中的拖动卡片通过阴影和少量缩放表达浮起。

### 9.2 颜色

- 默认跟随 Windows 深浅色和强调色；
- 品牌色只用于入口标识和关键主操作；
- 警告、错误、成功使用语义色并配合图标/文字；
- 普通硬件数值不使用红黄绿渐变；
- 背景对比度必须在动态壁纸和浅色窗口上保持可读。

### 9.3 圆角

| 元素 | 建议圆角 |
| --- | ---: |
| 面板 | 16～20 |
| 卡片 | 12～16 |
| 按钮 | 6～10 |
| 标签/徽标 | 高度的 50% 或 6～8 |

同一层级不得混用大量不同圆角。

## 10. 字体与数字

- 使用 Windows 系统字体和 Segoe UI Variable；
- 正文最小 12sp，常规正文 13～14sp；
- 卡片标题 14～16sp、Semibold；
- 大数字按卡片尺寸使用 24～36sp；
- 小号文字增加少量字距，标题可轻微收紧；
- 监控数字使用 tabular figures，避免宽度跳动；
- 单位作为次级信息，字号和对比度降低但仍可读；
- 中英文混排遵循系统语言，不在同一组件无理由混用。

## 11. 状态设计

### 11.1 Loading

- 首次加载使用与最终结构近似的骨架；
- 不显示无限旋转器覆盖整张卡片；
- 超过 2 秒显示解释文字；
- 用户仍可打开设置或取消联网。

### 11.2 Empty

- 说明“为什么为空”；
- 提供一个明确下一步，例如“新建待办”；
- 不使用大面积插画挤占工作台。

### 11.3 Stale/Offline

- 继续显示最后有效数据；
- 显示更新时间和离线标识；
- 不把缓存数据表现成实时值；
- 网络恢复后自动刷新并移除状态。

### 11.4 PermissionRequired

- 说明权限用途；
- 提供“允许”和“暂不”；
- 拒绝后卡片仍可被移除或改用降级模式；
- 不重复弹出系统授权。

### 11.5 Error

- 用户可读错误摘要；
- 重试；
- 查看诊断；
- 禁用卡片；
- 不展示调用栈和内部路径。

## 12. 便签、待办与剪贴板细节

### 12.1 便签

- 点击正文直接编辑，不再打开多余弹窗；
- 自动保存状态以小型文字或图标表示；
- `Ctrl+Z/Y` 作用于文本时优先文本历史；
- 离开编辑后才把 `Ctrl+Z/Y` 交给布局；
- 支持 `Ctrl+Enter` 快速完成/退出编辑。
- Markdown 模式由用户显式开启，预览与源文编辑可以往返切换；
- 预览首版只强调标题、列表、引用、代码和常见行内标记，不引入复杂工具栏；
- 复制动作复制原始正文，不复制预览控件的排版结果。

### 12.2 待办

- 勾选后立即反馈，数据确认失败时回滚并解释；
- 删除进入短时撤销条，不使用确认框打断；
- 到期和优先级不只依赖颜色；
- 已完成项目默认折叠。

### 12.3 剪贴板

- 敏感内容默认一行遮罩；
- 图片先显示低分辨率缩略图；
- 文件条目显示文件名和数量，不自动读取完整内容；
- 点击条目将其设为当前剪贴板，提供瞬时完成反馈；
- 支持键盘选择和 `Enter`；
- “暂停捕获”在卡片和隐私设置中都可见。

## 13. 键盘与焦点

### 13.1 默认键位

| 操作 | 键位 |
| --- | --- |
| 关闭当前层/面板 | `Esc` |
| 切换焦点 | `Tab` / `Shift+Tab` |
| 激活 | `Enter` / `Space` |
| 面板内搜索 | `Ctrl+F` |
| 添加卡片 | `Ctrl+N`（上下文允许时） |
| 进入/退出编辑 | 可配置，默认不占用系统常见快捷键 |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y` |

### 13.2 焦点规则

- 面板打开时焦点优先恢复上次位置；首次打开位于标题区或首张卡片；
- 面板关闭后焦点语义返回入口；
- 模态窗口关闭后返回触发控件；
- 拖动结束后焦点保持在被拖动卡片；
- 焦点指示必须始终可见，不得只在键盘模式下突然改变布局。

## 14. 无障碍与偏好适配

### 14.1 减少动态效果

- 面板使用 120～180ms 交叉淡化；
- 禁止大位移、缩放和弹簧超调；
- 卡片让位可瞬时或短淡化；
- 保留按压颜色反馈和状态变化。

### 14.2 减少透明度

- 面板和卡片背景提高至近实色；
- 禁用模糊；
- 增加清晰边框或分层阴影。

### 14.3 高对比度

- 使用系统高对比度资源；
- 禁止硬编码低对比度灰色；
- 图标轮廓、文本和焦点使用系统颜色。

### 14.4 屏幕阅读器

每张卡片提供：

- 名称；
- 类型；
- 当前摘要；
- 新鲜度；
- 主操作；
- 展开/折叠状态；
- 错误或权限状态。

实时系统监控不得每秒向屏幕阅读器播报。只在用户聚焦或跨越严重阈值时更新可访问文本。

## 15. 多显示器与缩放

- 位置以显示器设备标识和逻辑坐标保存；
- 显示器消失时保留其布局，不删除；
- 同一布局在 DPI 变化后重新计算实际像素；
- 面板不能跨越两个显示器；
- 入口和面板必须处于同一显示器；
- 不依据显示器数组索引持久化配置；
- 任务栏移动或 Shell 修改工具导致无法确认位置时进入安全降级。

## 16. 设计验收清单

- [ ] 按下反馈在 50ms 内可见。
- [ ] 面板来源与入口空间位置一致。
- [ ] 开关动画可在任意帧反向。
- [ ] 拖动保持抓取偏移并 1:1 跟随。
- [ ] 点击与拖动不会同时触发。
- [ ] 卡片布局无重叠、无随机跳位。
- [ ] 高频数据更新不会造成文本宽度抖动。
- [ ] 面板关闭后无持续动画或 VSync 等待。
- [ ] 深色、浅色、高对比度均可读。
- [ ] 减少动态效果和减少透明度有真实替代方案。
- [ ] 键盘可完成核心流程。
- [ ] 错误、离线、过期和无权限状态可区分。
