# M2.2.2 LYT-001/002/005 卡片布局 ViewModel

状态：已完成；便携 SDK 下 Debug/Release 75/75 测试、WorkspacePanel 构建和 WinUI smoke 均通过
关联需求：LYT-001、LYT-002、LYT-005
关联 ADR：ADR-0003

## 目标

在 M2.2.1 纯布局函数之上增加一个不依赖 XAML、数据库和视觉树的卡片布局状态层，为后续 ItemsRepeater 接入提供稳定的 Items/Placements 快照和可测试的卡片操作边界。

## 本次交付

- 新增 `CardLayoutViewModel`，维护当前有效列数、卡片输入顺序和布局结果；
- 根据有效宽度切换 2/4/6 列，并通过 `ResponsiveGridLayout` 重新排布；
- 提供 `ReplaceItems`、`AddCard`、`RemoveCard`、`ResizeCard` 和 `TryGetPlacement`；
- 对外暴露只读卡片与布局快照，避免调用方直接修改内部列表；
- 布局计算成功后才替换状态，重复 ID 等非法输入不会破坏上一份有效快照；
- 通过 `INotifyPropertyChanged` 发布列数、卡片和布局结果变化，保持 ViewModel 可被后续 UI 层订阅。

## 明确不做

- 不接入 ItemsRepeater、XAML、WorkspacePanel 视觉树或数据库；
- 不实现拖动预览、让位动画、真实鼠标落位、编辑模式、撤销/重做或持久化；
- 不把 ViewModel 的单元测试表述为真实卡片布局交互已完成。

## 验收证据

- `UT-GRID-007`：替换卡片后 Items/Placements 快照和属性通知一致；
- `UT-GRID-008`：有效宽度变化后列数和跨度重排保持输入顺序；
- `UT-GRID-009`：新增、改尺寸、删除按确定性规则重排；
- `UT-GRID-010`：重复 ID 等非法输入失败时保留上一份有效快照；
- `UT-GRID-011`：未知卡片查询和操作不改变现有状态；
- Debug/Release UnitTests 均为 75/75；WorkspacePanel Debug/Release 构建均为 0 警告、0 错误；WinUI Debug/Release smoke 均返回 0。

ItemsRepeater 接入、真实拖动落位和释放后的持久化仍需后续工作包及真实鼠标验收。
