# M2.3.4 通用卡片状态视觉与示例快照

状态：已完成（2026-08-11）

关联需求：CRD-001、CRD-002、CRD-005、NFR-A11Y-001～005、NFR-I18N-001～004

关联规范：`docs/02-ux-design-spec.md` 第 11、13、14 节

关联 ADR：ADR-0002、ADR-0003、ADR-0017（本工作包不改变进程、IPC、持久化、
布局或插件边界；真实桌面脚本沿用验收实例隔离约束）

## 冻结范围

本包在 WorkspacePanel Runtime 层提供无 WinUI、无网络、无 IPC、无数据库和无副作用的
`CardRuntimeStatusPresentation`。它接收不可变 `CardRuntimeSnapshot`，使用本地化资源解析器
和可选的确定性时间格式化器，输出供 XAML 使用的状态视觉值和严格动作门禁。

WorkspacePanel 的五种既有卡片模板复用一个状态模板，只消费 presentation，不改变 Runtime
生命周期、视口调度、ItemsRepeater、布局或拖拽合同。示例状态来自现有内存快照或单元测试
快照，不加入默认持久化布局，不代表真实 Provider、网络恢复、权限授予或数据库状态已完成。

## 状态合同

`CardRuntimeStatus` 已有 `Unknown`、`Loading`、`Ready`、`Empty`、`Stale`、`Offline`、
`PermissionRequired`、`Unavailable`、`Error`、`Disabled` 十个值。未知/非法值安全归一为
`Unknown`，不暴露动作和 payload 内容。

`Ready + freshness=stale` 在不改变快照 `Status` 的前提下使用 Stale 标题、摘要和更新时间；
`Error` 始终优先于 stale freshness，但非空 payload 仍可见以保留最后有效数据。
`Status=Stale` 和 `Status=Offline` 仅在有非空 payload 时保留内容并显示快照时间。

默认 `{}`、`null`、`undefined` 视为无 payload；非空对象、非空数组以及合法 JSON primitive
视为有 payload。presentation 不输出 `ErrorCode` 或 payload 文本。

## 资源键合同

状态标题/摘要：

```text
CardStatus.Unknown.Title / CardStatus.Unknown.Summary
CardStatus.Loading.Title / CardStatus.Loading.Summary
CardStatus.Ready.Title / CardStatus.Ready.Summary
CardStatus.Empty.Title / CardStatus.Empty.Summary
CardStatus.Stale.Title / CardStatus.Stale.Summary
CardStatus.Offline.Title / CardStatus.Offline.Summary
CardStatus.PermissionRequired.Title / CardStatus.PermissionRequired.Summary
CardStatus.Unavailable.Title / CardStatus.Unavailable.Summary
CardStatus.Error.Title / CardStatus.Error.Summary
CardStatus.Disabled.Title / CardStatus.Disabled.Summary
```

新鲜度文本：

```text
CardStatus.Freshness.Stale
CardStatus.Freshness.Offline
```

资源解析器返回空值时，Presentation 使用资源键本身作为稳定回退；时间格式化器由调用方
注入，未注入时使用当前区域设置的本地时间短格式。MRT Core 会把 `.resw` 名称中的点号
编译为 PRI 层级路径，因此 WorkspacePanel 适配器在调用 `ResourceLoader` 前把 `.` 转为 `/`。

## API 输出

`CardRuntimeStatusPresentation` 输出：

- `Status`、`Freshness`；
- `Title`、`Summary`、`FreshnessText`、`AutomationSummary`；
- `HasPayload`、`IsStateVisible`、`IsContentVisible`、`IsLoading`、`IsCritical`、
  `HasFreshnessText`；
- `CanRetry`、`CanRefresh`、`CanEdit`、`CanConfigure`、`CanOpenDiagnostics`、
  `CanDisable`。

动作属性仅反映快照 `AllowedActionIds` 中已有 ID，不执行动作、不推断未知动作、不新增
`Enable` 或权限授权动作。本包不渲染无法执行的占位业务按钮；真正的 Retry、Diagnostics、
Disable 等动作呈现和路由仍需后续工作包。

## UI 接入

- `CardSurfaceItem` 持有与当前不可变快照对应的 presentation，并在快照更新后发布
  `RuntimePresentation` 属性变更；
- Notes、Timer、Todo、Calendar 和 Unknown 五个模板共享静态状态模板，并分别暴露唯一
  UIA 状态锚点；
- Loading 使用静态骨架，不含 `ProgressRing`、Storyboard、shimmer 或周期动画；
- 状态表面只使用 `ThemeResource`，Error 额外使用 `!` 与文本摘要，信息不只依赖颜色；
- Timer、Todo、Calendar 原有的固定 Start/Open 占位按钮已移除，避免把内容可见性误当成
  动作授权；Unknown 继续保持无业务动作的安全降级；
- 中英文资源键保持对称；Stale、Offline、Error 摘要对空 payload 使用条件中立措辞。

  CoreBroker，并清除继承的 Broker 会话凭据；Release x64 输出
  `REAL-CARD-STATUS-PASS`。当前 zh-CN 桌面上 Notes、Timer、Todo、Calendar 四个可见
  UIA 锚点均读到“暂不可用”，三个未建模主动作不存在，关闭按钮使进程以 0 退出；
- 更新后的 `Test-CardDragInteraction.ps1 -WithBroker` 继续使用 ADR-0017 的独立
  GUID、token 和临时数据根，输出 `REAL-DRAG-PASS`；四卡 handle/surface 拖拽、
  NoteBodyBox 控件隔离和 `Esc` 取消未回退。

上述真实桌面证据只覆盖当前 Unavailable 状态、动作缺失门禁和既有拖拽路径。Loading、
Stale、Offline、Error 的真实 UI 状态切换、英文运行时资源、屏幕阅读器、高对比度、
文本缩放、多显示器/DPI 和性能矩阵均未在本包完成。
