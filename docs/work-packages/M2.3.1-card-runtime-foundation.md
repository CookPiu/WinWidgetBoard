# M2.3.1 CRD-001/002/005 统一卡片运行时基础

状态：已完成代码、自动测试和当前桌面四卡回归
关联需求：CRD-001、CRD-002、CRD-005、LYT-002
关联 ADR：ADR-0002、ADR-0003

## 目标

在不改变现有四卡视觉与交互的前提下，为 WorkspacePanel 建立统一、可测试的
卡片定义、实例、生命周期和不可变快照契约，消除模板层直接依赖演示实例 ID 的
硬编码，并为后续可见性调度、设置草稿和真实数据 Provider 留出稳定边界。

## 实现范围

- 定义内置卡片类型、标题资源键、默认尺寸和支持尺寸；
- 为每个布局实例创建独立的 `CardRuntimeInstance`；
- 建立 `Created / Initialized / Visible / Hidden / Suspended / Disposed`
  生命周期状态机；
- 建立含 schema、sequence、UTC 时间、新鲜度、状态、payload、允许动作和
  稳定错误码的不可变快照；
- 对乱序快照、未知枚举状态和实例/类型不匹配做安全拒绝或降级；
- 提供实例级异步刷新错误边界，失败时保留上一份 payload，且不改变其他实例；
- 将现有便签编辑器状态映射到便签卡片快照；
- 将现有四卡模板选择从实例 ID 切换为运行时卡片类型 ID。
- 为未知类型提供无业务按钮的安全模板，仍保留布局编辑中的缩放和移除入口。

## 明确不包含

- 不实现视口、面板可见性或 Provider 的实际调度；
- 不创建卡片私有定时器、后台循环、网络请求或新 IPC；
- 不实现设置草稿、数据库迁移或插件运行时；
- 不补齐计时器、待办和日历业务；
- 不进行第二轮视觉美化，也不改变拖动、缩放、便签编辑和布局持久化行为。

## 验收标准

- 卡片定义拒绝无效 ID、重复尺寸和不受支持的默认尺寸；
- 快照 payload 与动作集合对调用方只读，sequence 只接受单调递增；
- 未知状态不暴露可执行动作，并返回稳定错误码；
- 合法生命周期转换可重复验证，非法转换被拒绝；
- 单个实例刷新异常只将该实例置为 Error，保留上一份 payload，其他实例不变；
- 调用方取消必须继续传播，不能伪装成卡片错误；
- 四个现有实例解析为稳定的卡片类型，布局重排后实例与运行时对象身份保持不变；
- 便签 Loading、Ready、Unavailable、Error 能同步到运行时快照；
- Debug/Release UnitTests 和 WorkspacePanel x64 构建通过。

## ADR 判断

本工作包只在 WorkspacePanel 内建立运行时对象和现有卡片适配，不改变进程边界、
任务栏集成、插件安全、数据持久化或许可证，因此无需新增 ADR。
