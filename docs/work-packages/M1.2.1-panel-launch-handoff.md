# M1.2.1 LauncherHost 到 WorkspacePanel 的进程启动交接

状态：最小交接 POC 已实现；真实桌面联动验收待完成
关联需求：SYS-001、LCH-003、PNL-003、PNL-004
关联 ADR：ADR-0002、ADR-0007

## 目标

在 CoreBroker、IPC 和持久化尚未实现时，先建立 LauncherHost 与 WorkspacePanel 之间可验证的同用户进程生命周期：

- LauncherHost 按显示器、工作区、入口矩形和 DPI 构造并传递启动上下文；
- 生产构建从 LauncherHost 同目录启动 WorkspacePanel，开发构建可使用临时环境变量覆盖路径；
- 已运行面板时尝试激活其顶层窗口，关闭时发送公开 `WM_CLOSE`；
- 通过进程句柄轮询面板退出，面板自行关闭后恢复 LauncherHost 的入口状态。

## 本次允许修改

- `src/LauncherHost`；
- 本工作包、ADR、实施计划、实施状态和测试说明文档。

## 实现

- `WorkspacePanelProcess.*`：解析面板路径，使用 `CreateProcessW` 启动子进程，传递四类矩形参数和 DPI，枚举同进程顶层窗口，执行激活/关闭/回收。
- `LauncherWindow.*`：入口释放时交接打开/关闭请求，并在可见性定时器中轮询面板进程，避免把已退出面板保留为打开状态。
- `main.cpp`：增加 `--panel-launch-smoke-test` 和 `--panel-lifecycle-smoke-test`；前者验证真实进程创建、启动上下文和面板 smoke 退出，后者验证正常窗口创建、`WM_CLOSE` 和干净退出。
- `WinWidgetBoard.LauncherHost.vcxproj`：登记新源文件，并显式链接 LauncherHost 已使用的 `Gdi32.lib`。

## 明确不实现

- 不引入命名管道、JSON Envelope、CoreBroker、数据库、卡片运行时或版本握手；
- 不向 Explorer 注入、不读取任务栏私有 XAML、不发送私有 Shell 消息、不使用窗口钩子；
- 不用 `TerminateProcess` 结束正常面板；仅在本工作包的 smoke 超时或异常清理时终止本次测试创建的子进程；
- 环境变量路径只用于本地开发验证，不成为用户设置、安装配置或安全边界；
- 当前自动化会话不具备可靠的前台窗口权限，因此不以 `SetForegroundWindow` 作为自动化通过条件；真实重复打开/激活仍需桌面验收。

## 自动验证

当前系统没有注册 .NET 10 SDK，WorkspacePanel 使用已校验的便携 SDK runtime。启动子进程时使用 `cmd.exe` 注入 runtime 和面板路径，避免 PowerShell `Start-Process` 环境变量大小写冲突：

```powershell
$dotnetRoot = 'C:\tmp\winwidgetboard-dotnet-10.0.302'
$panel = (Resolve-Path '.\artifacts\bin\WinWidgetBoard.WorkspacePanel\Release\net10.0-windows10.0.26100.0\win-x64\WinWidgetBoard.WorkspacePanel.exe').Path
$launcher = (Resolve-Path '.\artifacts\manual-build\LauncherHost\Release\WinWidgetBoard.LauncherHost.exe').Path
$command = 'set "DOTNET_ROOT=' + $dotnetRoot + '" && set "DOTNET_ROOT_X64=' + $dotnetRoot + '" && set "WINWIDGETBOARD_WORKSPACE_PANEL=' + $panel + '" && "' + $launcher + '" --panel-launch-smoke-test'
& cmd.exe /d /c $command
$LASTEXITCODE

$command = 'set "DOTNET_ROOT=' + $dotnetRoot + '" && set "DOTNET_ROOT_X64=' + $dotnetRoot + '" && set "WINWIDGETBOARD_WORKSPACE_PANEL=' + $panel + '" && "' + $launcher + '" --panel-lifecycle-smoke-test'
& cmd.exe /d /c $command
$LASTEXITCODE
```

本次验证结果：

- LauncherHost Debug/Release 通过 MSVC 直接编译和链接，均为 0 警告、0 错误；
- Debug/Release `--panel-launch-smoke-test` 均返回 0；
- Debug/Release `--panel-lifecycle-smoke-test` 均返回 0；
- 面板路径不存在时，`--panel-launch-smoke-test` fail closed，返回专用退出码 18；
- 当前 Visual Studio MSBuild 在 FileTracker 初始化阶段因环境 `E_ACCESSDENIED` 失败，因此本次不把完整 `.sln`/MSBuild 结果表述为通过；
- 以上 smoke 不替代真实 Windows 11 桌面上的前台激活、任务栏点击、失焦关闭、多显示器/DPI、全屏和 Explorer 重启验收。
