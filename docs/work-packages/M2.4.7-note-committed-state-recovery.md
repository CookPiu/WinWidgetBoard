# M2.4.7 NTE-001 便签已提交状态恢复回归

状态：已完成代码、自动测试和当前桌面进程重启恢复回归
关联需求：NTE-001、AC-005、NFR-REL-002
关联 ADR：ADR-0010、ADR-0011、ADR-0012、ADR-0013

## 目标

证明便签保存成功后，即使 WorkspacePanel 和 CoreBroker 进程被终止并重新启动，编辑器仍通过 `notes.get` 读取 SQLite 中最后一次已提交的标题、正文和正文格式。

本工作包中的“恢复”指最后一次已提交状态恢复，不是跨重启版本历史。当前文档没有批准版本历史表、历史保留策略或恢复历史 IPC；这些内容必须单独定义需求并新增 ADR 后再实现。

## 实现范围

- 增加文件型 SQLite 关闭后重新打开的便签读取回归 `UT-NOTE-027`；
- 增加临时 `LOCALAPPDATA` 进程回归脚本；
- 首次启动通过真实 UI Automation 写入唯一正文并等待“已保存”状态；
- 终止 WorkspacePanel 与 CoreBroker，保留临时数据库后重新启动；
- 通过 UI Automation 验证标题和正文均恢复为首次提交值；
- 不新增数据库表、IPC 方法、历史版本 UI 或多便签创建/删除功能；
- 不恢复或新增键盘移动需求。

## 自动验证
