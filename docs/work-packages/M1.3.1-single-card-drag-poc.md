# M1.3.1 单张假卡片拖动与点击互斥 POC

状态：交互控制器与 WorkspacePanel 接入已完成；真实鼠标验收待完成
关联需求：LCH-003、LYT-004
关联规范：UX 动效规范第 7.2 节、第 8 节
关联 ADR：ADR-0003

## 目标

在尚未接入布局引擎、卡片数据和持久化之前，先验证一张假卡片的真实输入契约：

- pointer-down 立即进入按下态，但移动未超过 10 逻辑像素时仍按点击处理；
- 超过阈值后提交拖动，卡片保持指针相对位移并使用 pointer capture；
- 释放区分点击与拖动，不同时触发两种行为；
- `Esc`、pointer canceled 或 pointer capture lost 恢复拖动前的位置；
- 拖动中以轻微缩放表达浮起，不引入持续循环动画。

## 实现边界

- 只接入第一张便签占位卡片的内容区域；卡片按钮仍保留独立点击行为；
- 控制器使用可测试的 `Idle → Pressed → Dragging → Idle` 状态机；
- 拖动只改变视觉位移，不修改网格顺序、不让位、不持久化；
- 不实现面板开关动画、卡片缩放、撤销/重做、CoreBroker、IPC 或真实卡片数据；这些继续由 M1.3 后续工作包负责。

## 真实桌面验收清单

- [ ] 从卡片非中心位置按下并移动，卡片保持抓取偏移，不跳到中心；
- [ ] 移动小于 10 逻辑像素后释放，仍按点击处理，不提交拖动；
- [ ] 移动超过 10 逻辑像素后，卡片 1:1 跟随指针；
- [ ] 移出卡片表面后仍跟随，释放后只提交拖动，不触发点击；
- [ ] `Esc` 或丢失捕获后卡片恢复到拖动前位置；
- [ ] 拖动时卡片轻微缩放，静止时恢复，不出现持续闪烁；
- [ ] 60Hz 与高刷新率显示器上无明显跳变或 fall-through；
- [ ] 高 DPI、深色/浅色主题、减少动态效果设置下行为可用。

完成本工作包只能表述为“单张假卡片输入 POC 已实现”。它不代表布局引擎、卡片编排、拖动让位或持久化已经完成。
