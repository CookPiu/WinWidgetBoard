# M1.3.3 单卡拖动取消回归动效 POC

状态：控制器与 WorkspacePanel 接入已完成；当前真实 Windows 11 会话验收通过，完整矩阵待完成
关联需求：LYT-004
关联规范：UX 动效规范第 7.2 节、第 8 节、第 14.1 节
关联 ADR：ADR-0003

## 目标

补齐 M1.3.1 单卡拖动 POC 在取消路径上的视觉连续性：

- `Esc`、pointer canceled 或 pointer capture lost 后，卡片从当前展示位置回到拖动起点；
- 回归使用可测试的临界阻尼控制器，不在取消操作中加入无来源的装饰性回弹；
- 回归期间再次按下卡片时，先读取当前展示位置，再开始新的 pointer gesture，不等待旧动画结束；
- Windows 减少动态效果开启时直接回到目标位置，不产生位移动画。

## 实现边界

- 仍只接入第一张便签占位卡片；
- 不实现网格让位、合法落点投影、卡片排序、缩放、删除、撤销/重做、持久化或真实卡片数据；
- 正常拖动释放仍保留当前 POC 的视觉位置，不把当前行为表述为完整布局落位；
- 回归动画只在取消路径运行，目标到达后立即停止计时器；
- 新指针按下可以打断回归，卡片拖动控制器同步到当前视觉偏移。
