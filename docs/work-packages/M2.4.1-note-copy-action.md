# M2.4.1 NTE-001 便签显式复制动作

状态：已完成代码与自动测试；真实桌面剪贴板回归待完成
关联需求：NTE-001
关联规范：便签交互与剪贴板显式操作规范
关联 ADR：ADR-0005、ADR-0013

## 目标

在现有单便签编辑卡片中增加明确的“复制便签”入口，复制标题和正文原文到 Windows 当前剪贴板，满足用户主动复制便签的需求。

## 实现范围

- 新增 UI 无关的 `NoteClipboardFormatter`，标题和正文均非空时使用系统换行连接；任一部分为空时不添加多余换行；
- 便签卡片新增双语“复制”按钮和 UI Automation 名称；
- 点击复制时通过 `DataPackage` 写入 Windows 当前剪贴板并调用 `Clipboard.Flush()`；
- 空便签和剪贴板访问失败分别显示明确状态；
- 不把复制内容写入 SQLite，不新增剪贴板历史表，也不改变自动保存或 revision 逻辑。

## 不在本工作包内

- Markdown 渲染或编辑工具栏；
- 多便签搜索结果和便签列表；
- 便签删除、完整撤销和恢复历史；
- Windows 剪贴板历史卡片。

- `UT-NOTE-011`：空标题、空正文和空便签不生成多余换行；
- Release UnitTests：113/113；
- WorkspacePanel Release x64 构建：0 警告、0 错误；
- WorkspacePanel Release x64 `--smoke-test`：退出码 0。

## 真实桌面验证

在可交互 Windows 桌面中启动当前 `x64\Release` 面板，等待便签加载后点击“复制便签”，再在外部文本编辑器粘贴，确认标题、正文和 Markdown 标记保持不变；空便签和剪贴板访问失败路径应显示对应状态。该验证需要真实剪贴板和前台桌面，不由单元测试替代。
