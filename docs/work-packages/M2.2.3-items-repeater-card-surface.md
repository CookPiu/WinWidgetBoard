# M2.2.3 LYT-001/002/005 ItemsRepeater 卡片视觉接入

状态：已完成；便携 SDK 下 Debug/Release 77/77 测试、WorkspacePanel 构建和 WinUI smoke 均通过
关联需求：LYT-001、LYT-002、LYT-005
关联 ADR：ADR-0003

## 目标

把 M2.2.2 的布局状态快照接入 WorkspacePanel 的 ItemsRepeater，使四张演示卡片使用统一的响应式列跨度和行跨度排布，同时保留已有便签编辑与演示拖动 POC。

## 本次交付

- 新增 `CardLayoutSurfaceViewModel` 和 `CardSurfaceItem`，将 `CardPlacement` 快照转换为可绑定的视觉数据；
- 新增 `CardSurfaceTemplateSelector`，为便签、计时器、待办和日历选择独立模板；
- 新增 `CardGridLayout`，按可用宽度、列跨度和行跨度测量/排列 ItemsRepeater 子项；
- WorkspacePanel 使用 ItemsRepeater 承载四张演示卡片，宽度变化时沿用 M2.2.2 的 2/4/6 列规则；
- 保留便签编辑器的加载、只读和自动保存绑定，以及原有演示卡片拖动输入边界；
- 新增 `UT-GRID-012/013`，覆盖视觉快照重排和便签状态传播。

## 明确不做

- 不实现编辑模式、尺寸控制、删除入口、真实拖动让位、释放落点或撤销/重做；
- 当前布局类使用 `VirtualizingLayout` 接口承载 ItemsRepeater，但本包按当前小规模快照创建全部项，不宣称虚拟化回收和性能门禁已完成；
- 不写入布局数据库，不把 WinUI smoke 表述为真实桌面视觉或鼠标验收。

## 验收证据

- `UT-GRID-012`：ItemsRepeater 视觉项随布局列数变化重新生成并保持 placement 快照；
- `UT-GRID-013`：便签状态和错误码变化传播到对应视觉项；
- Debug/Release UnitTests 均为 77/77；WorkspacePanel Debug/Release 构建均为 0 警告、0 错误；WinUI Debug/Release `--smoke-test` 均返回 0。

真实桌面布局目视、ItemsRepeater 虚拟化回收、编辑模式和真实鼠标拖动仍需后续工作包及人工验收。
