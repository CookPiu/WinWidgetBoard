# M2.4.8 NTE-001 多便签只读列表与安全导航

状态：已完成代码与自动测试；真实桌面 UI Automation 回归待完成
关联需求：NTE-001、NFR-A11Y-002
关联 ADR：ADR-0010、ADR-0012、ADR-0013

## 目标

在不改变现有数据库和 IPC 契约的前提下，提供一个显式入口读取所有已保存便签，并复用已有搜索结果与草稿保护规则打开所选便签。

## 实现范围

- 增加“全部”入口，调用现有 `notes.search` 的空查询语义；
- `NoteSearchViewModel` 增加 `LoadAllAsync` 和 `Listing` 状态，保留取消、错误和结果映射边界；
- 结果列表继续使用 `NoteEditorViewModel.LoadNoteAsync`，未保存草稿时禁止切换；
- 增加英语/简体中文按钮、列表加载、结果、空列表和失败状态；
- 增加 UI Automation 入口，使用临时 `LOCALAPPDATA` 创建并列出一条已保存便签；
- 不增加便签创建、删除、重命名、版本历史、数据库表或 IPC 方法；
- 不恢复或新增键盘移动需求。
