# M2.2.6 LYT-003/004 真实指针拖动与释放提交

状态：已完成代码接入；M2.2.7 已修复落点边界与视觉变换回收缺陷；便携 SDK 下 Debug/Release 87/87 测试、WorkspacePanel 构建和 WinUI smoke 均通过，真实桌面人工验收待完成
关联需求：LYT-003、LYT-004、LYT-005
关联 ADR：ADR-0003

## 目标

把 M2.2.5 的拖动投影核心接入 WorkspacePanel 的真实 Pointer 事件链：编辑模式下从拖动把手按下开始捕获指针，卡片保持 1:1 位移，释放时提交最近合法网格 placement，取消和捕获丢失回到原位置。

## 本次交付

- 所有演示卡片在编辑工具栏提供拖动把手；
- 拖动把手使用 `PointerPressed/PointerMoved/PointerReleased` 和 pointer capture，普通模式不启动拖动；
- 拖动过程中使用 `CardDragController` 连续更新 `CompositeTransform`，并按当前卡片 placement 计算目标单元；
- 释放时通过 `CardLayoutEditViewModel.TryCommitDrop` 校验并提交 `CardPlacement`，同步更新 `PreferredColumn`；
- `CardLayoutViewModel.ApplyPlacements` 对数量、ID、跨度、边界和重叠做原子校验；
- 捕获丢失、`Esc` 或无合法落点时沿现有可中断回归路径返回；
- 增加提交 placement 和编辑取消恢复测试。

## 明确不做

- 当前未实现其他卡片实时让位预览、目标槽位可视化、释放动画的速度交接或惯性投影；
- 不实现布局数据库持久化、20 步撤销/重做和 ItemsRepeater 虚拟化回收；
- WinUI smoke 只验证进程构造/退出，不等价于真实鼠标捕获、DPI、刷新率和视觉布局验收。

- 真实桌面人工验收：待用户执行编辑模式、拖动把手、捕获丢失、Esc、释放提交和 DPI 场景清单。
