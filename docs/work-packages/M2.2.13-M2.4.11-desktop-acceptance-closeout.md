# M2.2.13 / M2.4.11 桌面验收与隔离收口

状态：当前单显示器环境已验收；完整硬件、无障碍和性能矩阵仍待完成
关联需求：LYT-001～006、NTE-001、DAT-001、NFR-REL-002、
NFR-PERF-006、NFR-A11Y-001～003
关联 ADR：ADR-0003、ADR-0010～0017

## 目标

对 M2.2 网格布局和 M2.4 快速便签的既有代码工作包进行真实桌面验收，修复验收
暴露的产品与测试缺口，并建立不会访问生产实例或用户数据库的可重复验收边界。

## 实现范围

- CoreBroker 和 WorkspacePanel 增加仅限验收/冒烟模式的 GUID 单实例身份；
- CoreBroker 增加仅限验收模式、仅限系统临时目录子路径的数据目录覆盖；
- 验收面板在 UI Automation 前台切换期间保持打开，生产失焦关闭行为不变；
- `CardGridLayout` 根据 `RealizationRect` 和推荐锚点只实现视口相交卡片，
  未请求元素继续使用 ItemsRepeater 默认自动回收；
- 四类卡片拖动柄和卡片网格增加稳定、唯一的 UI Automation 锚点；
- 便签固定高度卡片增加内部滚动区，编辑与操作入口在卡片内可达，拖动表面和
  编辑模式工具栏不随内容滚动；
- 修复删除其他便签后重新打开默认便签时被同 ID 快速路径错误短路的问题；
- UIA 脚本补齐四卡双入口拖动、交互控件隔离、`Esc` 取消、按钮和
  `Ctrl+Z`/`Ctrl+Y`、2/4/6 列、布局保存重启、便签完整交互链路；
- 脚本在异步 UIA 状态传播处使用有界等待，超时仍按产品失败处理。

## 数据安全复核

收口过程中确认旧脚本依赖 `LOCALAPPDATA` 的隔离假设无效后，立即停止写入型测试，
先备份并恢复用户数据库，再改为显式临时数据目录。隔离修复后的完整写入回归结束后，
只读复核便签、布局和布局项三张表的行数与基线哈希全部一致。备份和数据库均未加入
Git。
