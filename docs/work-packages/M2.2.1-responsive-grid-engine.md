# M2.2.1 LYT-001/002/005 响应式网格核心

状态：已完成；便携 SDK 下 Debug/Release 70/70 测试、WorkspacePanel 构建均通过
关联需求：LYT-001、LYT-002、LYT-005
关联 ADR：ADR-0003

## 目标

实现不依赖 WinUI、数据库或绝对像素的纯布局函数，为后续卡片运行时和真实拖动落位提供可测试的确定性基础。

## 本次交付

- 根据有效逻辑宽度选择 2、4、6 列；
- 映射 S/M/L/W/XL 到规定的列跨度和行跨度；
- 使用稳定输入顺序执行 top-left first-fit compacting；
- 在 2 列网格中将 W/XL 的列跨度收缩到可用宽度；
- 支持可选 preferred column，并在列数变化时安全限制到有效范围；
- 保证排布结果无重叠、无越界且输入相同则结果一致；
- 新增 100 张随机卡片的边界和无重叠属性测试。

## 明确不做

- 不接入 ItemsRepeater、XAML 或 WorkspacePanel 视觉树；
- 不实现拖动预览、合法落点动画、编辑模式、缩放、删除、撤销/重做；
- 不写入数据库，也不把本工作包描述为完整布局交互完成。
