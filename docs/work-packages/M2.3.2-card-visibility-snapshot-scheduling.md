# M2.3.2 CRD-003 可见性与快照调度

状态：已完成代码、自动测试和当前桌面四卡回归

关联需求：CRD-002、CRD-003、CRD-005、NFR-PERF-003、NFR-PERF-007、PNL-004

关联 ADR：ADR-0002、ADR-0003、ADR-0009、ADR-0017

## 目标

在 M2.3.1 卡片运行时基础上，使用单一集中协调器管理面板和 ItemsRepeater
视口的可见性，并在 Hidden→Visible 时请求一次本地新鲜快照。隐藏卡片不执行
纯 UI 快照刷新；面板关闭、元素回收、卡片移除和窗口释放均取消或隔离在途工作。

## 实现范围

- `CardRuntimeVisibilityScheduler` 集中注册全部 `CardRuntimeInstance`，按
  `panelVisible && isInViewport` 计算目标状态；注册初始进入 `Initialized→Hidden`
  或 `Initialized→Visible`。
- 每个注册实例使用受限取消令牌和 generation。Ready 与 Error 快照提交共用
  当前注册、当前 generation、当前 Visible 的提交门禁；门禁失效后迟到结果不会
  写入已隐藏、注销或释放的实例。
- 单实例最多保留一个当前刷新和一个取消中前置刷新，使用单个待刷新标志吸收
  快速信号，不创建卡片 Timer、永久循环或无界队列。Dispose 获取 commit gate
  和等待在途刷新 completion 共享 250ms 总预算，可由测试传入更短的超时；
  runtime 自身仍执行同步、无 Provider I/O 的本地释放。
- `CardSurfaceItem` 为现有内置四卡提供本地快照工厂适配；未知卡和占位卡只生成
  递增 sequence 的本地占位快照，不新增网络、IPC 或业务动作。
- `CardLayoutSurfaceViewModel` 负责运行时注册、注销和视口状态转发；重排删除时
  先注销旧 runtime，复用同一布局实例 ID 时仍以 runtime 对象身份校验旧元素信号。
- MainWindow 仅转发 `RequestOpenMotion`/`RequestCloseMotion` 的面板状态，以及
  ItemsRepeater 的 `ElementPrepared`/`ElementClearing` 实现视口信号。显式
  `UIElement→CardRuntimeInstance` 映射保证回收事件只作用于准备时的 runtime；
  ItemsSource null→rebind 前清空映射和视口状态，避免元素复用后旧实例持续
  Visible 或新实例被旧 clearing 误隐藏。
- 便签状态在 Hidden 时继续保留于 `NoteEditorViewModel`，但不推进卡片运行时
  sequence；恢复 Visible 后由一次本地新鲜快照同步最新状态。

## 明确不包含

- 不改变现有四卡视觉、拖动、缩放、便签编辑或布局持久化；
- 不新增 Provider、网络请求、IPC、数据库迁移、插件能力或进程边界；
- 本工作包只使用 Visible/Hidden 协调，不引入新的 Suspended 业务策略；
- 当前视口以 ItemsRepeater 公开的实现/回收生命周期为准；近视口缓存和拖动
  recommended anchor 可继续保持 active，严格像素级 EffectiveViewport 属于后续；
- 不实现真实 Provider 的周期、退避、节能、网络恢复或跨实例请求合并；
- 不把真实桌面任务栏、DPI、多显示器和帧时间验证替代为单元测试。

## 生命周期与提交门禁

调度器在每个注册实例上以独立 commit gate 串行化“状态失效”和“快照提交”，但
不会在调度器字典锁内调用 runtime 或 Provider 外部代码。注销先从注册表移除并
递增 generation，再释放 runtime；因此旧元素、旧 Provider 和旧错误回调都只能被
丢弃，不能污染新注册实例。

刷新执行在离开调度器字典锁前先登记不可空的 completion task，Dispose 因而不会
漏掉“已注册但尚未发布 Task”的并发窗口。异常生命周期被移出注册表时同步取消
现有 Provider；获取多个实例 commit gate 和等待所有 completion 共用同一个
250ms 总预算。

和 runtime identity 单元测试覆盖。严格 EffectiveViewport、隐藏后 GPU/VSync、
Provider 降频和硬件性能矩阵仍未测量，不能由本次回归代替。

## ADR 判断

本工作包只在 WorkspacePanel Runtime/Layout/UI 事件转发边界内实现，不改变进程、
IPC、持久化、插件安全或许可证边界，因此无需新增 ADR。
