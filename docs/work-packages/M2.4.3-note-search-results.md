# M2.4.3 NTE-001 便签搜索结果展示

状态：已完成代码、自动测试和当前桌面搜索回归
关联需求：NTE-001、PNL-006、NFR-A11Y-002
关联规范：面板标题区搜索与便签结果展示规范
关联 ADR：ADR-0013

## 目标

将现有面板标题区搜索框接入已经存在的 `notes.search` IPC 能力，展示便签匹配结果，满足 NTE-001 的搜索入口要求。

## 实现范围

- 新增可测试的 `NoteSearchViewModel`，负责 debounce、旧查询取消、空查询清理、错误状态和结果快照；
- 将匹配便签映射为标题和有界纯文本预览，最多使用 CoreBroker 返回的结果上限；
- WorkspacePanel 标题区搜索框改为搜索便签，结果以有限高度列表展示；
- 增加中英文状态文案和搜索结果 UI Automation 名称；
- 结果展示为只读，不在本工作包内切换编辑中的便签，不新增删除、多便签编辑或 Markdown 渲染。

## 不在本工作包内

- 多便签选择后加载到编辑器；
- 新增、删除、归档和恢复便签；
- Markdown 渲染和编辑工具栏；
- 卡片类型全局筛选；
- Windows 剪贴板历史卡片。
