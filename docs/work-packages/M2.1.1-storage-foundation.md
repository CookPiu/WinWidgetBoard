# M2.1.1 SQLite 本地存储基础

状态：已完成；Debug/Release 构建和 39/39 单元测试通过
关联需求：DAT-001、NFR-REL-002、NFR-REL-003、NFR-SEC-002
关联 ADR：ADR-0002、ADR-0005

## 目标

为 M2.1 后续布局、卡片和本地内容仓储提供可测试的 SQLite 基础：可注入数据库路径、版本化 schema migration、事务回滚、迁移前备份和文件/内存模式配置。

## 范围

- `schema_migrations` 与 schema v1；
- 卡片定义/实例、布局/布局项、便签、待办、本地日历事件和计时器的关系表；
- foreign keys、文件数据库 WAL、内存数据库分支；
- 已有文件数据库执行新迁移前的可识别备份；
- migration 失败或备份失败时不继续执行；
- Debug/Release 单元测试。
- 不新增 NuGet SQLite 包；使用 Windows 11 系统 `winsqlite3.dll`，并在启动/测试时对系统组件缺失安全失败。

## 明确不做

- 不接入 CoreBroker `Program` 或现有 Named Pipe/IPC 路由；
- 不实现卡片、布局、便签、待办、日历或计时器 CRUD；
- 不实现布局算法或 WorkspacePanel UI；
- 不创建剪贴板历史表，也不持久化剪贴板正文；
- 不把本工作包描述为 M2.1 全部完成。

## 验收证据

- `SqliteMigrationTests` 覆盖首次初始化、幂等迁移、事务失败回滚、迁移前备份、备份失败保护、foreign key/WAL/内存模式和剪贴板表缺失；
- 使用仓库锁定的便携 .NET SDK 完成 Debug/Release 构建和测试；
- 记录依赖版本及其许可证来源。
