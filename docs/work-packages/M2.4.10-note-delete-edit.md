# M2.4.10 NTE-001 多便签删除与安全编辑

状态：已完成代码与自动测试；真实桌面 UI Automation 回归待完成
关联需求：NTE-001、NFR-REL-002、NFR-A11Y-002
关联 ADR：ADR-0010、ADR-0012、ADR-0013、ADR-0016

## 目标

在现有多便签列表中继续安全打开便签编辑，并增加带 revision 保护和二次确认的
删除能力。删除失败时不得丢失当前编辑内容或列表项。

## 实现范围

- 搜索结果携带 `UpdatedAtUtc`，删除请求使用该 revision；
- 当前便签增加删除入口，删除成功后清空编辑器并安全切换到剩余第一条便签；
- 列表项增加删除入口，列表项点击继续打开现有编辑器；
- 有未保存草稿、正在加载/保存或 CoreBroker 不可用时阻止删除；
- 增加中英文删除确认、状态文案和 UI Automation 名称；
- 不新增 IPC 方法、数据库表、版本历史、删除撤销或键盘移动功能。
