# M2.2.4 LYT-003 布局编辑模式与卡片操作门禁

状态：已完成；便携 SDK 下 Debug/Release 80/80 测试、WorkspacePanel 构建和 WinUI smoke 均通过
关联需求：LYT-003、LYT-005
关联 ADR：ADR-0003

## 目标

为 M2.2.3 的卡片视觉层增加显式编辑模式边界，保证正常模式不响应卡片拖动、缩放和删除操作；进入编辑后提供可取消的工作快照。

## 本次交付

- 新增 `CardLayoutEditViewModel`，提供 `BeginEdit`、`CommitEdit`、`CancelEdit`；
- 编辑开始时保存布局快照，取消时原子恢复进入编辑前的卡片顺序和尺寸；
- 只有编辑模式允许缩放和删除，普通模式的操作返回失败且不改变布局；
- ItemsRepeater 卡片项同步 `IsEditing`，仅编辑模式显示缩小、放大和移除入口；
- `Esc` 在编辑模式下取消编辑并恢复快照，编辑按钮在“编辑/完成”之间切换；
- 保留现有拖动 POC，但现在只有编辑模式才会启动演示卡片拖动控制器；
- 中英文资源、AutomationProperties 名称和状态提示已补齐。

## 明确不做

- 不实现真实网格拖动投影、让位预览、释放落点或跨卡片移动；
- 不实现 20 步撤销/重做、布局持久化、添加卡片和虚拟化回收；
- 单元测试和 smoke 不等价于真实鼠标、键盘和视觉可用性验收。

## 验收证据

- `UT-GRID-014`：普通模式拒绝缩放和删除，编辑模式允许操作；
- `UT-GRID-015`：取消编辑恢复进入编辑前快照；
- `UT-GRID-016`：完成编辑保留工作布局；
- `CardLayoutSurfaceViewModelTests`：编辑状态传播到 ItemsRepeater 视觉项；
- Debug/Release UnitTests 均为 80/80；WorkspacePanel Debug/Release 构建均为 0 警告、0 错误；WinUI Debug/Release `--smoke-test` 均返回 0。

真实桌面编辑模式、真实鼠标拖动和布局持久化仍需后续工作包及人工验收。
