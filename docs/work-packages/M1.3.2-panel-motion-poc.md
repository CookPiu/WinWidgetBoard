# M1.3.2 面板锚定开关与可中断反向 POC

状态：控制器与 WorkspacePanel 接入已完成；当前真实 Windows 11 会话动效验收通过，完整显示器矩阵和定量性能记录待完成
关联需求：PNL-003、PNL-004、NFR-PERF-004、NFR-PERF-005
关联规范：UX 动效规范第 8.2～8.4 节
关联 ADR：ADR-0002、ADR-0007

## 目标

为 WorkspacePanel 建立从 LauncherHost 入口所在角展开、沿同一路径关闭、可在中途反向的最小动效边界：

- 打开从入口方向的轻微位移、0.985 缩放和透明度 0 开始；
- 默认使用临界阻尼数值积分，不使用装饰性弹跳；
- 关闭、`Esc`、面板外失焦、关闭按钮和 `WM_CLOSE` 汇入同一关闭路径；
- 反向时保留当前展示值和速度，避免动画“撞墙”；
- Windows 减少动态效果开启时，只保留短淡入淡出，不做位移和缩放。

## 实现边界

- 位移作用于原生顶层面板窗口本身（按 DPI 转换为物理屏幕像素），缩放作用于 `RootGrid` 的 `CompositeTransform`；透明度优先同步到原生顶层窗口的 `WS_EX_LAYERED` Alpha，使面板背景表面与内容一起移动和淡入淡出；不支持时透明度回退到 `RootGrid.Opacity`；
- 动效定时器只在 Opening/Closing 期间运行，达到目标后立即停止；
- 不实现真实布局、卡片让位、数据加载、IPC、持久化或全屏策略；
- M1.3.1 单卡拖动仍保持独立输入控制器，面板动效不锁定卡片输入。
