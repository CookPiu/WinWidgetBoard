# M2.3.10 天气位置设置 UI、IPC 与本地持久化

状态：已完成
关联需求：WEA-001、SET-001、SET-003、DAT-001、NFR-REL-002、NFR-PRI-003
关联 ADR：ADR-0021

## 目标

把 M2.3.3 已完成的设置草稿合同接入一个真实用户可操作的天气位置设置纵切面：

```text
WorkspacePanel SettingsButton
    ↓ WeatherSettingsDialog / WeatherSettingsViewModel
CardSettingsDraft
    ↓ CoreBrokerWeatherSettingsClient
weather.settings.get/save Named Pipe
    ↓ revision + idempotency validation
WeatherSettingsRepository / SQLite schema v3
    ↓
WeatherProviderRuntime 替换请求 key
    ↓ Loading → Scheduler → Open-Meteo → cards.snapshot
Weather card
```

## 本包范围

- 天气位置名称、纬度、经度的双语设置对话框；
- `CardSettingsDraft` 到 IPC 的两阶段提交；
- `weather.settings.get` / `weather.settings.save`；
- SQLite `weather_settings` 表、迁移前备份和 revision 冲突保护；
- 保存后的 Provider 注册替换、Loading 快照和当前可见性继承；
- 自动化测试、真实 UI Automation 和文档同步。

## 明确排除

- 自动定位权限；
- 城市搜索或地理编码；
- 跨重启天气 payload 缓存；
- OS 网络/电源事件；
- 多 Provider、多天气实例和天气预报。
