# M2.3.0 UI 基础样式与共享卡片外壳

状态：已完成（2026-08-10）
关联需求：PNL-006、PNL-007、LYT-003、CRD-004、NFR-A11Y-001、
NFR-A11Y-003、NFR-A11Y-005、NFR-I18N-004
关联规范：UX、视觉与动效规范第 1、5、9、10、14 节
关联 ADR：ADR-0002、ADR-0003、ADR-0017

## 目标

在不改变已验收布局、拖拽、数据和焦点行为的前提下，建立 WinUI 3 可复用的基础
视觉层，提升面板、标题区、卡片、输入与操作区的层级、密度和一致性。

## 允许修改

- WorkspacePanel 应用级 XAML 资源和 `MainWindow.xaml`；
- 只读视觉/XAML 契约测试；
- 布局编辑真实 UIA 验收脚本的模式可见性检查；
- 本工作包、实施计划、README 和实施状态。

## 禁止修改

- 网格尺寸选择、placement、拖拽投影和持久化；
- CoreBroker、IPC、数据库和用户数据；
- 面板开关或卡片让位动效参数；
- 品牌名称、品牌色、图标和插画；
- 新卡片功能或 M2.3 卡片运行时状态模型。

## 实现要点

- 使用四像素间距、统一圆角、系统字体和可解释字号建立设计 Token；
- 复用 WinUI 主题画刷，不硬编码品牌色，保留亮色、暗色和高对比度适配；
- 标题信息与命令分层，搜索和操作区使用统一 40 逻辑像素命中高度；
- 四张卡片共享同一卡片外壳、标题、正文、主操作和编辑工具栏样式；
- 便签输入、预览、状态和动作使用共享控件样式；
- 正常模式下编辑工具栏必须折叠，进入编辑后才出现；
- 不添加装饰性循环动画、额外模糊或多层透明材料。

## 已知边界

- 本工作包使用 WinUI 系统主题画刷并以 XAML 契约禁止硬编码颜色，但暗色、高对比度、
  文本缩放和多显示器/DPI 的完整人工矩阵仍属于后续无障碍与兼容性验收；
- 未加入 Mica/Acrylic、品牌色、图标、动画或卡片运行时状态，因此不代表 M2.3
  统一卡片运行时已经完成；
- UnitTests 在当前离线环境仍输出既有 NuGet 源不可访问 `NU1801` 警告；测试本身
  167/167 通过，WorkspacePanel 编译结果无警告。
