# M2.0.2 Named Pipe 当前用户传输与握手 POC

状态：当前用户 Named Pipe、CoreBroker 单实例、共享客户端、`session.hello`/`session.ping`、客户端请求超时、定时心跳、基础断线重连、WorkspacePanel 后台会话和 LauncherHost 原生客户端已完成；锁定便携 SDK 下的 31/31 回归、双配置构建和真实 CoreBroker 进程 smoke 已通过；真实业务方法、幂等命令恢复和完整重启恢复待完成
关联需求：G-006、SYS-001、NFR-REL-001
关联规范：技术架构第 4.3、12 节；接口与数据契约第 1、2 节
关联 ADR：ADR-0002、ADR-0007、ADR-0008

## 目标

把 M2.0.1 的协议编解码放入真实 Windows 进程间传输边界：

- CoreBroker 使用稳定的 `WinWidgetBoard.CoreBroker.v1` Named Pipe 名称；
- 服务端和客户端使用 `PipeOptions.CurrentUserOnly`，同时限制用户账户和提升级别；
- 每条消息继续使用 4 字节 little-endian 长度帧和 1MiB 上限；
- 首条请求必须是 `session.hello`，token、客户端类型、架构和协议范围通过校验后才建立会话；
- 握手后的最小 `session.ping` 用于验证连接仍可用；
- 客户端请求具备独立连接/请求超时，周期心跳在瞬时断管或超时后按间隔继续尝试；
- 客户端在已有连接断开或请求超时后执行一次握手重连，再重试当前请求；
- CoreBroker 使用本用户 Local mutex 拒绝重复实例。

## 本次允许修改

- `src/CoreBroker/`、`src/CoreBroker.Client/`、`src/LauncherHost/`；
- `src/WorkspacePanel/Ipc/` 与 WorkspacePanel 项目引用；
- `src/Contracts/Protocol/SessionHello.cs` 与协议版本规则；
- `tests/UnitTests/`、解决方案、实施计划、实施状态、测试说明和本工作包文档。

## 实现边界

- 不接入 LauncherHost 或 WorkspacePanel 的业务调用；
- 不实现数据库、卡片快照、布局命令、Provider 或插件管道；
- 不把 `PipeOptions.CurrentUserOnly` 表述为跨用户或管理员安全沙箱；
- 本次只提供 `session.ping` 作为保活方法，不接入真实业务方法；客户端定时心跳、请求超时和基础自动重连属于本工作包；
- session token 仅从受控构造参数/环境变量或 smoke 内存传递，禁止写日志；
- `--pipe-handshake-smoke-test` 只验证当前进程内启动的真实 Named Pipe，不代表生产部署和重启恢复已完成。
