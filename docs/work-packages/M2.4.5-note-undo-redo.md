# M2.4.5 NTE-001 便签编辑撤销与重做

状态：已完成代码与自动测试；真实桌面按钮回归待完成
关联需求：NTE-001、NFR-A11Y-002
关联规范：便签编辑撤销/重做与草稿状态规范
关联 ADR：ADR-0011、ADR-0013

## 目标

为便签标题和正文编辑提供显式撤销、重做入口，满足 NTE-001 的撤销要求，同时保持当前自动保存和内存草稿策略。

## 实现范围

- `NoteEditorViewModel` 保存标题/正文快照，最多保留 20 步撤销历史；
- 撤销和重做均产生新的待保存草稿，并复用现有 debounce、revision 和失败保留逻辑；
- 新编辑会清空 redo 历史；加载其他便签或标记不可用时清空历史；
- WorkspacePanel 增加双语撤销/重做按钮、可访问名称和状态提示；
- 本工作包只处理便签文本编辑，不引入跨重启历史数据库。

## 不在本工作包内

- 卡片键盘移动或任何已撤销的键盘移动需求；
- 完整版本历史、跨重启恢复和历史时间线；
- Markdown 语义级操作历史；
- 多窗口并行编辑或冲突合并 UI；
- Windows 剪贴板历史卡片。

## 自动验证

- `UT-NOTE-020`：撤销和重做恢复正文快照并继续自动保存；
- `UT-NOTE-021`：新输入清空 redo 历史；
- `UT-NOTE-022`：撤销历史严格限制为 20 步；
- Debug/Release UnitTests：目标为 124/124；
- WorkspacePanel Debug/Release x64 构建和 WinUI smoke：目标为 0 警告、0 错误、退出码 0。

## 真实桌面验证

在可交互 Windows 桌面中启动当前 `x64\Release` 面板，编辑便签标题和正文，点击撤销/重做按钮，确认文本、按钮启用状态和保存状态正确；撤销后关闭并重开，确认最终已保存文本保留。该验证需要真实文本框、按钮焦点和前台桌面，不由单元测试替代。
