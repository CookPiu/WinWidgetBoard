# M2.2.7 LYT-004 拖动落点与视觉状态修复

状态：已完成代码修复；便携 SDK 下 Debug/Release 87/87 测试、WorkspacePanel 构建和 WinUI smoke 均通过，真实桌面回归待用户确认
关联需求：LYT-004、LYT-005
关联 ADR：ADR-0003

## 缺陷表现

真实拖动提交后，卡片偶发吸附到错误位置，或在 ItemsRepeater 重绑/回收后沿用旧的拖动平移值，表现为卡片跑出面板边界或暂时消失。

## 修复内容

- 在 ItemsRepeater 重新绑定前清零拖动卡片的 `CompositeTransform`，防止视觉偏移被回收到其他卡片；
- 释放时使用最终指针位置重新计算目标网格单元，不再依赖最后一次 `PointerMoved` 的旧落点；
- 将网格落点计算抽成纯函数，按卡片跨度夹紧列边界，并安全处理负行和异常宽度；
- 增加落点边界与最终释放偏移回归测试。
