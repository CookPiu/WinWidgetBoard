# M1.1 无注入入口 POC

状态：已实现，真实桌面验收待完成
关联需求：SYS-003、SYS-004、SYS-005、SYS-006、LCH-001～LCH-005
关联 ADR：ADR-0001、ADR-0002

## 目标

在不注入 `explorer.exe`、不读取任务栏私有 XAML、不修改注册表的前提下，验证 `LauncherHost` 的最小入口边界：

- 通过 `GetMonitorInfoW` 获取显示器与工作区矩形；
- 通过公开 `SHAppBarMessage` 获取任务栏状态和可用位置提示；
- 从工作区差异推断任务栏边缘；
- 几何不明确或自动隐藏时退回工作区边缘位置；
- 创建无标题、无任务栏按钮、非激活的透明 Win32 入口窗口；
- 仅圆角按钮区域命中，其他区域返回透明命中；
- 支持按下/释放取消、右键菜单和显示环境变化后的重定位；
- 全屏前台窗口覆盖显示器时隐藏入口。

## 明确不实现

- 不进入 `explorer.exe`，不使用 DLL 注入、XAML Diagnostics 或私有视觉树；
- 不修改任务栏设置、Widgets 设置、注册表或启动项；
- M1.1 本身不启动 WorkspacePanel；面板 Toggle 的最小进程交接后续由独立的 M1.2.1 工作包实现，本工作包仍只负责入口边界；
- 不实现 CoreBroker、IPC、卡片、持久化、全局快捷键或安装；
- 不把公开 `ABM_GETTASKBARPOS` 误认为系统按钮边界。当前入口放在工作区安全边缘，不能宣称已完成“原 Widgets 精确替换”。

## 实现

- `TaskbarGeometry.*`：定义任务栏边缘、入口模式、显示器快照和确定性矩形解析；包含底部/顶部/左右任务栏、自动隐藏、异常矩形、DPI 缩放和工作区边界检查。
- `LauncherWindow.*`：实现 layered popup、圆角按钮绘制、`WM_NCHITTEST` 透明命中、pointer capture、右键菜单、`WM_DISPLAYCHANGE`、`WM_SETTINGCHANGE`、`WM_DPICHANGED`、电源恢复、`TaskbarCreated`、排除 Explorer 桌面窗口误判的全屏轮询和可见状态下的 `HWND_TOPMOST` 层级保持。
- `main.cpp`：保留 M1.0 隐藏消息窗口 smoke；新增 `--geometry-smoke-test`，普通启动创建入口窗口。

## 真实桌面验收清单

以下项目必须在真实 Windows 11 交互会话中完成，不能由本工作包的自动 smoke 代替：

- [ ] 入口不覆盖开始、搜索、任务按钮和系统托盘；
- [x] 在当前真实 Windows 11 交互会话中，点击桌面空白不会触发全屏隐藏；普通最大化窗口不会遮挡入口，入口点击可打开 WorkspacePanel；

- [ ] 按下立即显示反馈，拖出后释放不切换状态；

- [ ] 单屏、双屏、负坐标和主显示器切换；
- [ ] 任务栏居中、左对齐、自动隐藏；
- [ ] Explorer 重启后入口只恢复一次；
- [ ] 睡眠恢复、显示器热插拔和全屏应用；
- [ ] 普通用户权限下运行；
