# M2.1.5 NTE-001 便签 CoreBroker IPC

状态：已完成；Debug/Release 58/58 单元测试通过
关联需求：NTE-001、DAT-001、NFR-REL-002、NFR-SEC-001
关联 ADR：ADR-0005、ADR-0010、ADR-0012

## 目标

把便签持久化仓储接入当前用户 CoreBroker 命名管道，为 WorkspacePanel 后续接入提供版本化、校验过的 IPC 边界。

## 本次交付

- 新增 `notes.save`、`notes.get`、`notes.search`、`notes.delete` 契约；
- save/delete 写操作使用 `clientOperationId` 有界幂等缓存；
- save/update/delete 复用便签 revision 冲突保护；
- IPC 层验证对象类型、必填字段、长度、时间戳和正文格式；正文上限 256 KiB；
- CoreBroker 正常启动时打开本地 SQLite 并注册 `NoteRepository`；测试服务器可继续使用无存储路由；
- 新增 IPC 集成测试，覆盖 capability、保存、重复请求、搜索、revision 冲突、删除和非法输入。

## 明确不做

- 不接入 WorkspacePanel UI 或 XAML；
- 不实现 IPC 客户端便签高层 API；
- 不把便签正文写入日志、剪贴板或错误 developer message；
- 不宣称 NTE-001 完整用户旅程完成。

## 验证

使用仓库锁定的便携 .NET SDK：

```text
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Debug --no-restore  # 58/58
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Release --no-restore # 58/58
```

当前环境仍会报告 NuGet 源不可访问的 `NU1801` 警告；本次测试使用已有缓存包，无新增网络依赖。
