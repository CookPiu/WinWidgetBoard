# M1.0 最小解决方案与工具链锁定

状态：实施中；本地分项目验收通过，完整解决方案、干净环境 CI 与人工窗口验证待完成
工程需求：BLD-001
关联 ADR：ADR-0002、ADR-0006

## 目标

建立 WinWidgetBoard 的最小、可重复构建的 x64 解决方案，不实现产品功能，为后续 M1.1 LauncherHost POC 提供受控基线。

## 允许修改

- 根目录解决方案、中央构建与包版本文件；
- `src/Contracts`；
- `src/LauncherHost`；
- `src/WorkspacePanel`；
- `tests/UnitTests`；
- 最小 CI、构建说明、依赖与许可证记录；
- `docs/status/implementation-status.md`。

## 禁止修改

- 不创建 `CoreBroker`、`PluginHost`、`Cards.BuiltIn` 或持久化项目；
- 不实现任务栏覆盖、任务栏几何、点击穿透或 Explorer 集成；
- 不实现 IPC 协议、SQLite、网络 Provider、插件安装或高级硬件访问；
- 不复制参考项目源码、图标、字体或其他资源；
- 不修改系统注册表、Widgets 设置或启动项。

## 锁定基线

- Visual Studio Community 2026：18.8.2；
- .NET SDK：10.0.302；
- Windows App SDK Runtime：2.3.1 stable；
- Windows App SDK WinUI：2.3.2；
- Windows SDK API 目标：10.0.26100.0；
- 首个技术验证架构：x64；
- C++ 语言标准：C++23。

具体 MSVC 工具集、Windows SDK BuildTools 和测试包版本以 `docs/development/toolchain.md` 与 `Directory.Packages.props` 为准。

## 验收标准

1. `WinWidgetBoard.sln` 只包含 Contracts、LauncherHost、WorkspacePanel 和 UnitTests。
2. Debug x64 与 Release x64 完整构建成功，Release 输出路径确定。
3. LauncherHost 仅创建普通隐藏消息窗口，不创建任务栏覆盖入口。
4. WorkspacePanel 可构造最小 WinUI 顶层窗口；M1.0 初始普通测试窗口现已由 M1.2 面板壳层替换。
5. `UT-BUILD-001 [BLD-001]` smoke test 通过。
6. 所有包版本集中且无浮动版本。
7. LauncherHost 不引用 WinUI、SQLite、HTTP 或插件运行时。
8. 构建和测试不要求管理员权限。
9. `git diff --check` 通过，工作树无意外生成文件。

## 最终自动验收

```powershell
dotnet restore .\WinWidgetBoard.sln
msbuild .\WinWidgetBoard.sln /m /p:Configuration=Debug /p:Platform=x64
msbuild .\WinWidgetBoard.sln /m /p:Configuration=Release /p:Platform=x64
dotnet test .\tests\UnitTests\WinWidgetBoard.UnitTests.csproj -c Release --no-restore
git diff --check
```

命令中的 `dotnet` 与 `msbuild` 必须解析为工具链文档记录的锁定版本。

当前托管会话没有系统安装的 .NET SDK。主智能体使用已校验 SHA-512 的官方便携 .NET SDK `10.0.302` 分别构建托管项目，并使用 Visual Studio MSBuild `18.8` 构建 LauncherHost。Debug/Release x64、locked-mode restore、单元测试和四个 `--smoke-test` 均已通过。由于便携 SDK 不注册到 Visual Studio 的 .NET SDK resolver，本机尚未完成上述单命令混合 `.sln` 构建；该项保留给安装了锁定 SDK 的干净环境和 CI 验证。
