# M2.3.7 cards.subscribe 实时事件传输

状态：已完成

关联需求：CRD-001、CRD-002、CRD-003、CRD-005、NFR-PERF-007、G-006

关联规范：`docs/03-technical-architecture.md` 第 10～12 节、
`docs/07-api-contracts.md` 第 15 节、`docs/08-testing-strategy.md` 第 6.5、8.1 节

关联 ADR：ADR-0002、ADR-0005、ADR-0017、ADR-0018、ADR-0019。

## 目标

把 M2.3.6 的 `CardStateSnapshot` 从 CoreBroker 内存边界接入当前用户 Named Pipe，
让 WorkspacePanel 能获得初始快照和异步 `cards.snapshot` 事件，并确保慢客户端不会让
CoreBroker 形成无界队列或静默丢失状态。

## 冻结范围

- `CardSnapshotSubscriptionHub` 保存最新快照并按连接维护至多一个订阅；
- `cards.subscribe` 完成实例 ID、可见实例子集、面板可见性和数量上限校验；
- 服务端事件写入循环与命令响应共享有序写锁，快照事件按实例合并；
- 默认 32 个待发送实例槽位溢出时取消连接并记录诊断，初始快照缓存默认最多 1024 个实例；
- `CoreBrokerPipeClient` 增加后台读取泵，分流响应和 Event Envelope；
- `CoreBrokerCardsClient` 接入 `CoreBrokerSession`，提供初始响应和快照事件解析；
- `CardSnapshotDispatcher` 提供 UI 调度器注入点、类型/schema/sequence 门禁和运行时映射。

## 明确不包含

- 真实天气或其他外部 HTTP Provider、DNS/TLS、网络权限和数据源 allowlist；
- SQLite Provider cache、last-success 持久化和隐私设置；
- OS 网络、电源、睡眠事件和性能/WPR/WPA 结论；
- 断线后跨连接自动恢复旧订阅，调用方需在新连接上重新提交订阅；
- WorkspacePanel 具体页面的 DispatcherQueue 注册和真实 Provider 数据展示；
- 第三方 Provider、PluginHost 和插件沙箱。

## 自动验证

- `UT-CARDS-001`：真实 CoreBroker Named Pipe 握手、能力声明、初始快照、异步事件和命令
  响应分流；
- `UT-CARDS-002`：按实例合并、有界队列和 overflow 断开信号；
- `UT-CARDS-003`：WorkspacePanel dispatcher 映射和旧 sequence 忽略；
- 全量 UnitTests Debug/Release；CoreBroker、WorkspacePanel Debug/Release x64 构建。

## 验收证据

- Debug UnitTests 276/276；
- CoreBroker、CoreBroker.Client 和 WorkspacePanel Debug 构建 0 警告、0 错误；
- 证据等级为 E1/E2：已证明本地 fake snapshot 的 IPC 事件链路和 UI runtime adapter，
  未证明真实 Provider、HTTP、缓存或 OS 事件。

## 完成门禁

- 事件不被客户端当作命令响应；
- 命令响应不进入可丢弃事件队列；
- 每连接订阅、事件缓冲、写入和取消均有界；
- overflow 关闭慢客户端并保留重新订阅路径；
- WorkspacePanel runtime 只接受合法且更新的快照；
- 文档、ADR、测试和实现状态同步，`git diff --check` 通过。
