# M2.3.8 WorkspacePanel 实时卡片订阅接入

状态：已完成

关联需求：CRD-001、CRD-002、CRD-003、CRD-005、NFR-PERF-007、NFR-REL-004

关联规范：`docs/03-technical-architecture.md` 第 10～12 节、
`docs/07-api-contracts.md` 第 15 节、`docs/08-testing-strategy.md` 第 6.5、8.1、9 节

关联 ADR：ADR-0002、ADR-0017、ADR-0019。

## 目标

将 M2.3.7 的 `cards.subscribe` 从可调用客户端接入 WorkspacePanel 实际运行时：
卡片运行时随布局增删注册/注销，初始快照和异步快照经过 UI DispatcherQueue 应用，
ItemsRepeater 视口变化使用单一去抖刷新订阅，CoreBroker 重连后自动恢复当前订阅。

## 冻结范围

- `CardSnapshotSubscriptionCoordinator` 维护订阅请求、运行时注册和初始快照应用；
- `MainWindow` 将 `CoreBrokerCardsClient`、`CardSnapshotDispatcher` 和当前四卡运行时接线；
- 订阅只读取当前布局实例 ID，已回收或删除的运行时从 dispatcher 注销；
- ItemsRepeater 准备/回收事件通过单一 100ms DispatcherQueueTimer 去抖，不创建每卡计时器；
- `CoreBrokerSession` 在心跳确认 Broker 重连且可见性重报成功后发出 `Reconnected`，
  WorkspacePanel 重新提交当前订阅；
- 关闭和释放路径取消订阅协调器、停止去抖计时器并注销事件处理器。

## 明确不包含

- 真实天气或其他外部 HTTP Provider、DNS/TLS、网络权限、缓存和数据源选择；
- Provider 结果到当前四卡业务 payload 的真实映射；
- 新增 IPC 方法、协议版本或数据库表；
- 完整 UIA/多显示器/DPI/性能矩阵人工验收；
- 第三方 Provider、PluginHost 和插件沙箱。

  Provider、HTTP、缓存或 OS 网络/电源事件。

## 完成门禁

- 后台事件不得直接修改 WinUI 或运行时通知对象，必须经过 UI dispatcher；
- 运行时替换、回收、释放和旧 sequence 事件均有门禁；
- 视口更新只有一个有界去抖计时器；
- Broker 重连后订阅恢复，不跨连接复用旧 subscription ID；
- 关闭路径不遗留事件订阅、后台应用任务或计时器；
- 文档、状态、测试和实现同步，`git diff --check` 通过。
