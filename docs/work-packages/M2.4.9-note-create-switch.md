# M2.4.9 NTE-001 新建便签并安全切换

状态：已完成代码与自动测试；真实桌面 UI Automation 回归待完成
关联需求：NTE-001、NFR-REL-002
关联 ADR：ADR-0010、ADR-0012、ADR-0013

## 目标

在当前便签没有未保存草稿、也没有进行中的保存或加载时，创建一条新的本地便签并立即切换编辑器到该便签。

## 实现范围

- 使用现有 `notes.save` 创建契约生成客户端唯一 `note-*` ID；
- 新建便签默认正文格式为 `plain-text`，标题和正文为空；
- 创建成功后更新编辑器的 note ID、revision、内容和撤销/重做边界；
- 创建期间禁用新建、切换和编辑相关操作；
- 创建失败保留当前便签和当前内容；
- 增加中英文新建按钮和状态文案；
- 不增加删除、重命名、版本历史、数据库表、IPC 方法或键盘移动功能。
