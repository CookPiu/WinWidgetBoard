# M2.2.5 LYT-004 拖动落点投影核心

状态：已完成；便携 SDK 下 Debug/Release 83/83 测试、WorkspacePanel 构建和 WinUI smoke 均通过
关联需求：LYT-004、LYT-005
关联 ADR：ADR-0003

## 目标

为真实拖动接入提供确定性的网格落点投影：给定当前 placement、卡片尺寸和指针投影到的目标单元，选择最近的合法位置，并保证不重叠、不越界。

## 本次交付

- 新增 `GridCell` 和 `CardDragPlacementProjector`；
- 对目标列进行尺寸感知的边界夹紧，对负行和越界行进行安全处理；
- 保留其他卡片当前 placement，搜索与目标单元距离最近的合法落点；
- 结果按原卡片输入顺序返回，具有确定性；
- `CardLayoutEditViewModel.TryPreviewDrop` 只在显式编辑模式下开放投影；
- 增加最近落点、越界夹紧、无重叠和编辑模式门禁测试。

## 明确不做

- 不接入真实 PointerPressed/PointerMoved/PointerReleased、pointer capture 或 1:1 抓取偏移；
- 不把投影结果提交到布局快照，不实现让位动画、取消回归、数据库持久化或撤销/重做；
- 单元测试不等价于真实 Windows 鼠标交互验收。

## 验收证据

- `UT-GRID-017`：冲突目标选择最近合法网格单元；
- `UT-GRID-018`：越界目标按卡片跨度夹紧并保持边界；
- `UT-GRID-019`：普通模式拒绝拖动投影，编辑模式允许预览；
- Debug/Release UnitTests 均为 83/83；WorkspacePanel Debug/Release 构建均为 0 警告、0 错误；WinUI Debug/Release `--smoke-test` 均返回 0。
