# M2.1.3 NTE-001 便签持久化仓储

状态：已完成；Debug/Release 53/53 单元测试通过
关联需求：NTE-001、DAT-001、NFR-REL-002
关联 ADR：ADR-0005、ADR-0010

## 目标

在现有 SQLite schema v1 和通用仓储边界上交付便签的持久化读写基础，为后续 UI 自动保存提供明确的 revision-safe 调用边界。

## 本次交付

- `NoteRecord` 与 `NoteBodyFormat`，支持纯文本和基础 Markdown；
- `NoteRepository.Create`、`Get`、`List`、`Search`、`Update`、`Delete`；
- `updated_at_utc` 规范化为 UTC round-trip 字符串，作为更新/删除的乐观并发令牌；
- 令牌不匹配返回 `NoteRevisionConflictException`，记录不存在返回 `NoteNotFoundException`；
- 搜索使用参数化 SQL 并转义 `%`、`_` 和反斜杠；
- 使用现有 `SqliteRepository`，所有写入继续经过持久化故障注入边界。

## 明确不做

- 不接入 CoreBroker IPC、WorkspacePanel 或任何 XAML/UI；
- 不实现防抖自动保存调度、撤销栈、复制交互或失败告警；
- 不实现待办、日历、计时器、布局或卡片仓储；
- 不持久化剪贴板正文。

## 验证

使用仓库锁定的便携 .NET SDK：

```text
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Debug --no-restore  # 53/53
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Release --no-restore # 53/53
```

当前环境仍会报告 NuGet 源不可访问的 `NU1801` 警告；本次测试使用已有缓存包，无新增网络依赖。
