# M2.2.9 LYT-006 布局逻辑位置重放修复

状态：已完成代码与自动验证；真实桌面验收待用户确认
关联需求：LYT-006、DAT-001、NFR-REL-002
关联 ADR：ADR-0014、ADR-0003、ADR-0005

## 缺陷

- 便签状态文本被静态 `x:Uid` 资源覆盖，加载成功后仍显示“正在加载本地便签”；
- 布局只保存 preferred column，重开时 first-fit 压缩空位，造成卡片位置混乱；
- 保存请求没有以当前 placement 的实际行列作为快照，重排后可能再次保存成默认位置。

## 修复

- 移除动态便签状态 TextBlock 的静态 `x:Uid`，让可测试 ViewModel 的状态通知成为唯一文本来源；
- 在布局契约、SQLite `layout_items`、仓储和 IPC 中增加 nullable `preferredRow`；
- 保存当前 placement 的行列，加载时优先恢复没有冲突的逻辑单元格，响应式越界时回退 first-fit；
- 保留旧数据库兼容路径，schema v1 数据在启动时通过 v2 迁移补列；
- 保留增删改尺寸的既有确定性重排规则，避免修复持久化时改变既有操作语义。
