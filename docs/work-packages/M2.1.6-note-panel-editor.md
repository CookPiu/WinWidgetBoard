# M2.1.6 NTE-001 WorkspacePanel 便签编辑器

状态：已完成；便携 SDK 下 Debug/Release 64/64 测试、WorkspacePanel 构建和 WinUI smoke 均通过
关联需求：NTE-001、DAT-001、NFR-REL-002
关联 ADR：ADR-0005、ADR-0011、ADR-0012、ADR-0013

## 目标

把 M2.1.5 的便签 IPC 接入 WorkspacePanel，形成“加载单条本地便签—编辑—debounce 自动保存—失败保留草稿”的最小用户路径。

## 本次交付

- `CoreBroker.Client` 新增 `INoteClient`、`CoreBrokerNotesClient` 和带 IPC 错误码的 `CoreBrokerClientException`；
- `CoreBrokerSession` 暴露高层便签客户端，但不向 UI 暴露底层管道；
- `NoteEditorViewModel` 提供加载、单便签 debounce、最新输入优先、revision token 传递、取消和失败草稿保留；
- WorkspacePanel 便签卡片加入标题/正文编辑区和本地化保存状态；
- 编辑区与原演示拖拽区域分离，保留已有拖拽 POC；
- 新增高层客户端 IPC 集成测试和 ViewModel 测试。

## 明确不做

- 不直接从 WorkspacePanel 打开 SQLite；
- 不把 IPC Envelope 组装逻辑写进 XAML code-behind；
- 不在本包宣称 Markdown 选择、便签搜索、删除、完整撤销/复制和多便签布局已完成；
- 不把未完成真实桌面输入验证表述为自动化通过。

## 验收证据

- `IT-NOTE-003/004`：高层客户端保存、读取、搜索、删除和 revision 错误码；
- `UT-NOTE-006`：加载现有便签不触发写入；
- `UT-NOTE-007`：输入 debounce 且只保存最新草稿；
- `UT-NOTE-008`：保存失败时草稿和错误状态保留；
- `UT-NOTE-009`：CoreBroker 不可用时编辑器离开加载态并保持只读；
- 使用仓库锁定的官方便携 .NET SDK `10.0.302` 运行 Debug/Release 测试和 WorkspacePanel 构建；测试均为 64/64，构建均为 0 警告、0 错误；设置便携 runtime 路径后 Debug/Release `--smoke-test` 均返回 0。

## 真实桌面验证

2026-08-08 用户确认：在同一 PowerShell 会话中使用同一 session token 启动 Release CoreBroker 和 WorkspacePanel 后，便签加载、编辑、debounce 自动保存、关闭后重新打开恢复、编辑区与卡片拖拽区域隔离均成功；CoreBroker 不可用时的只读状态也已验证。
