# M2.2.12 LYT-006 布局撤销与重做

状态：已完成代码、自动测试和当前单屏按钮/快捷键回归；屏幕阅读器与完整焦点矩阵待完成
关联需求：LYT-006
关联规范：UX 动效与布局规范第 7.4 节、第 13.1 节
关联 ADR：ADR-0003、ADR-0014、ADR-0015

## 目标

为显式布局编辑会话提供最多 20 步的布局撤销/重做，覆盖移动、缩放和删除操作，并保证未完成的编辑不会污染已提交布局。

## 实现范围

- `CardLayoutEditViewModel` 在进入编辑时建立工作快照，并维护独立的 undo/redo 历史；
- 每个成功的移动、缩放或删除作为一个历史命令；无效操作和没有实际变化的落点不进入历史；
- 历史最多保留 20 步；新操作会清空 redo 栈；
- 点击“完成”或按 `Esc` 取消时清空历史；取消仍恢复进入编辑前的快照；
- WorkspacePanel 标题区在编辑模式显示“撤销”和“重做”按钮，并根据历史状态禁用不可用操作；
- RootGrid 接入 `Ctrl+Z` / `Ctrl+Y`，复用同一 ViewModel 命令；
- 恢复历史时沿用现有布局状态层和 ItemsRepeater 结构同步，不写数据库；只有点击“完成”才保存最终布局。

## 不在本工作包内

- 添加卡片、便签完整能力和待办 CRUD；
- 让位弹簧补间、虚拟化回收压力和多显示器/DPI 矩阵；
- 真实桌面焦点保持、屏幕阅读器播报和文本框原生编辑历史的完整人工验收。
