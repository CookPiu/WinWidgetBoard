# M2.3.9 Open-Meteo 天气 Provider 垂直切片

状态：已完成代码、自动测试、真实 HTTPS 与真实桌面链路验收
关联需求：WEA-001、CRD-001、CRD-002、CRD-003、CRD-005、NFR-PERF-007、NFR-REL-004、NFR-PRI-003
关联 ADR：ADR-0018、ADR-0019、ADR-0020

## 目标

将首个真实天气数据源接入现有 Provider 调度和卡片订阅链路，形成：

```text
Open-Meteo HTTPS
    ↓
OpenMeteoWeatherProvider
    ↓  Scheduler 15 分钟/超时/退避/可见性
ProviderCardSnapshotAdapter
    ↓
CardSnapshotSubscriptionHub
    ↓  cards.snapshot
WorkspacePanel Weather runtime/card
```

## 本包范围

- 使用 `https://api.open-meteo.com/v1/forecast` 的 `current` 天气字段；
- 默认位置为 Singapore：纬度 `1.3521`、经度 `103.8198`；
- 只发送位置标签和经纬度，不发送账号、设备标识或自动定位结果；
- 可见实例按 15 分钟集中刷新；面板关闭、实例离开视口或连接断开时暂停；
- 解析温度、体感温度、湿度、风速、WMO 天气码和当地观测时间；
- 64 KiB 响应上限、429 Retry-After、网络错误、HTTP 错误和无效 JSON 的显式状态；
- 当前进程内按位置隔离的最近成功 payload 回退；
- Weather runtime、状态锚点、来源链接和默认卡片模板。

许可、OS 网络/电源事件或完整桌面性能。真实网络请求和真实桌面链路只证明当前环境下该
endpoint 的一次可达性、协议兼容性和本地进程链路，不替代长期稳定性/商业发布验收。
