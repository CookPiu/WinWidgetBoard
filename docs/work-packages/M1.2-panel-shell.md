# M1.2 面板壳层与确定性几何

状态：壳层已实现；真实桌面交互与性能验收待完成
关联需求：PNL-001～PNL-007、NFR-PERF-004、NFR-PERF-005
关联 ADR：ADR-0001、ADR-0002、ADR-0003、ADR-0006

## 目标

建立可独立启动、可测试、不会跨越工作区的 WorkspacePanel 最小壳层，为后续 LauncherHost 交接、IPC、卡片运行时和动效提供稳定边界。LauncherHost 的最小进程交接由独立的 M1.2.1 工作包负责：

- 从显示器、工作区、入口矩形和 DPI 计算确定性窗口矩形；
- 创建无普通任务栏按钮的独立 WinUI 3 工具窗口；
- 提供标题区、搜索框、操作入口、垂直滚动内容区和占位卡片；
- 支持基础的失焦关闭、`Esc` 关闭和模态作用域保护；
- 使用双语资源、系统主题资源和键盘焦点，保留无障碍验证入口。

## 启动上下文

M1.2 暂不接入 IPC。为验证跨进程数据形状，WorkspacePanel 接受以下命令行参数；跨进程启动交接、进程关闭和状态轮询见 [M1.2.1 工作包](M1.2.1-panel-launch-handoff.md)：

```text
--monitor-rect=left,top,right,bottom
--work-area=left,top,right,bottom
--launcher-rect=left,top,right,bottom
--dpi=96
```

四类参数必须同时存在；矩形必须有效，DPI 必须在 48～768 之间。未提供任何上下文参数时，面板从当前窗口的主显示器读取公开 `DisplayArea` 工作区，并使用当前窗口 DPI；这只是独立启动 fallback，不代表 LauncherHost 已完成交接。

## 实现

- `Shell/PanelLaunchContext.cs`：解析并校验矩形、DPI 和启动上下文，拒绝不完整或越界数据。
- `Shell/PanelGeometry.cs`：在工作区内计算 42%～48% 目标宽度、85%～94% 目标高度、680～960 逻辑像素宽度限制和 10 逻辑像素边距；处理高 DPI、负坐标、小工作区和无效几何。
- `MainWindow.xaml/.cs`：使用 `AppWindow`、`WS_EX_TOOLWINDOW` 和无标题栏 presenter，提供标题区、搜索、按钮、滚动区域、占位卡片、键盘焦点、外部失焦关闭和 `Esc` 关闭。
- `App.xaml.cs`：使用本地单实例互斥体；`--smoke-test` 在构造真实 `MainWindow` 后显式退出，避免未激活窗口调用应用退出 API 的运行时差异。
- `Strings/*/Resources.resw`：提供中文和英文标题、按钮、卡片文本及 AutomationProperties 名称。
- `tests/UnitTests/PanelGeometryTests.cs`：覆盖工作区边界、DPI 缩放和无效上下文 fail closed。

## 明确不实现

- 本工作包不修改 LauncherHost 的启动交接，不实现 IPC、CoreBroker、数据库、卡片数据或持久化；最小同用户进程交接由 M1.2.1 单独验证；
- 不实现打开/关闭动效、从当前值反向、拖拽编排或入口与面板的真实点击联动；这些属于 M1.3 或后续工作包；
- 不访问任务栏私有 XAML，不注入 Explorer，不修改注册表、Widgets 设置或启动项；
- 不宣称已通过真实任务栏位置、DPI、多显示器、全屏、Explorer 重启、键盘和 UI Automation 验收；
- 不把命令行上下文验证当作 IPC 契约完成，也不把 smoke 时间当作 NFR-PERF-004/005 的性能结论。


## 真实桌面验收清单

以下内容必须在真实 Windows 11 交互会话中完成，不能由构建、单元测试或 smoke 代替：

- [ ] 面板在入口所在显示器、同一工作区内打开，不跨屏、不覆盖任务栏和系统关键区域；
- [ ] 无普通任务栏按钮、无 Alt+Tab 普通应用项，普通用户权限可运行；
- [ ] 标题区、搜索框、添加/编辑/设置/关闭按钮和四个占位卡片布局可读；
- [ ] `Tab`、`Shift+Tab`、`Enter`、`Space`、`Esc` 和屏幕阅读器名称符合预期；
- [ ] 单击面板外关闭；文本输入和显式模态作用域期间不误关；
- [ ] 100%、125%、150%、200% DPI，负坐标、多显示器和显示器热插拔；
- [ ] 深色、浅色、高对比度、减少透明度和减少动态效果替代样式；
- [ ] 记录从入口按下到首帧、到基础可交互的时间，并单独验证 NFR-PERF-004/005；
- [ ] 记录面板关闭后的进程生命周期、工作集、CPU 和是否持续等待 VSync。
