# M2.1.4 NTE-001 便签自动保存服务层

状态：服务层已完成；Debug/Release 56/56 单元测试通过
关联需求：NTE-001、DAT-001、NFR-REL-002
关联 ADR：ADR-0010、ADR-0011

## 目标

为便签输入提供与 UI 无关的 debounce 自动保存边界，保证快速连续输入只提交最新内容，保存失败时保留内存草稿并返回可展示的错误。

## 本次交付

- `NoteAutosaveDraft`：封装新建或带 revision 的更新草稿；
- `NoteAutosaveCoordinator`：单便签 debounce 调度、最新任务优先、取消和异步释放；
- `NoteAutosaveResult`：返回成功记录或保存异常；
- 失败时保留 `InMemoryDraft`，不进行无界重试；
- 测试覆盖 debounce 保存、旧任务取消/最新输入胜出和写入失败后的草稿保留与重试。

## 明确不做

- 不接入 WorkspacePanel、XAML、CoreBroker IPC 或真实文本输入控件；
- 不实现 UI 告警、撤销栈、复制交互、失焦策略或多便签调度；
- 不宣称 NTE-001 完整用户旅程已验收，真实 UI 交互仍待完成。

## 验证

使用仓库锁定的便携 .NET SDK：

```text
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Debug --no-restore  # 56/56
dotnet test tests/UnitTests/WinWidgetBoard.UnitTests.csproj -c Release --no-restore # 56/56
```

当前环境仍会报告 NuGet 源不可访问的 `NU1801` 警告；本次测试使用已有缓存包，无新增网络依赖。
