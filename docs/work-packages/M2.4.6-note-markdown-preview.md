# M2.4.6 NTE-001 便签基础 Markdown 预览

状态：已完成代码与自动测试；真实桌面 UI Automation 回归待完成
关联需求：NTE-001、NFR-A11Y-002
关联规范：便签编辑、预览与保存状态规范
关联 ADR：ADR-0010、ADR-0012、ADR-0013

## 目标

为便签增加可选择的基础 Markdown 模式和原生预览入口。编辑区继续保存原始 Markdown 文本，预览区将最小块级语法转换为可读的 WinUI 内容。

## 实现范围

- 增加 Markdown/纯文本模式切换，保存请求分别携带 `markdown` 或 `plain-text`；
- 加载已有便签时恢复其正文格式，默认以编辑态打开；
- 支持标题、无序列表、有序列表、引用、围栏代码和常见行内代码/强调/链接的最小预览；
- 预览与源文编辑可往返切换，复制动作仍复制原始正文；
- 预览格式化器和正文格式保存行为放在可测试 ViewModel/无 UI 代码层；
- 卡片拖动入口将 Markdown 复选框、预览列表和滚动区域视为交互控件，避免编辑模式下抢占拖动。

## 不在本工作包内

- 第三方 Markdown 解析库、HTML/WebView、复杂富文本工具栏；
- 表格、脚注、嵌套列表、任务列表和语义级 Markdown 编辑；
- 跨重启版本历史、多便签管理或协作；
- 卡片键盘移动或任何已撤销的键盘移动需求。
