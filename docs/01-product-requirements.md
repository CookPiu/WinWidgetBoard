# WinWidgetBoard 产品需求文档

文档状态：已批准基线
版本：0.1
日期：2026-08-06
适用阶段：M1～M3

## 1. 产品摘要

WinWidgetBoard 是一款 Windows 11 本地优先快捷工作台。用户可关闭系统自带 Widgets 任务栏入口，并通过本应用放置在任务栏左下角的按钮打开半屏面板。面板由可编排卡片组成，覆盖天气、便签、日历、计时器、待办、剪贴板、系统监控等高频信息和轻操作。

产品不是 Windows Shell 替换器，也不以注入 Explorer 的方式接管微软组件。它通过独立窗口在视觉和使用流程上完成替代。

## 2. 问题陈述

Windows 11 自带 Widgets 存在以下体验缺口：

- 信息流与用户主动配置的工具混杂；
- 卡片功能偏展示，输入和操作能力有限；
- 面板视觉层级、密度和个性化能力不足；
- 用户无法建立一个本地优先的日常工作台；
- 无法将便签、剪贴板、计时器、系统监控等工具统一到一个入口；
- 系统级面板的资源、联网和内容策略不完全由用户掌控。

WinWidgetBoard 需要解决的核心问题不是“再做一个桌面小组件”，而是提供一个安静、快速、可靠、可组合的个人工作面板。

## 3. 产品原则

1. **本地优先**：无账号也能使用核心功能。
2. **入口克制**：任务栏只占用一个按钮，不持续堆放信息。
3. **功能优先**：卡片支持真实输入和操作，不只是展示。
4. **用户掌控**：联网、剪贴板、账号和插件权限均由用户决定。
5. **渐进呈现**：摘要在卡片表面，复杂配置进入卡片详情或设置。
6. **稳定优先**：稳定版不注入 Explorer，不依赖私有 XAML。
7. **性能可量化**：用资源预算和测量证据定义“轻量”。
8. **视觉平静**：不使用新闻流、广告、装饰性循环动画和过度模糊。

## 4. 目标与非目标

### 4.1 产品目标

- G-001：提供一个可在 300ms 内进入可交互状态的半屏工作台。
- G-002：允许用户通过网格自由组合高频卡片。
- G-003：面板关闭时保持极低 CPU、GPU 和内存占用。
- G-004：核心卡片在无网络、无账号、无管理员权限时可用。
- G-005：对 Windows 任务栏自动隐藏、DPI、多显示器、Explorer 重启有可靠恢复能力。
- G-006：为后续第三方卡片提供版本化、安全隔离的扩展基础。
- G-007：在视觉和交互上形成一致、克制、可中断的动效语言。

### 4.2 非目标

- NG-001：不替换 Windows Shell、开始菜单或通知中心。
- NG-002：不劫持或重映射系统保留的 `Win+W`。
- NG-003：不在稳定通道注入 `explorer.exe`。
- NG-004：不首发跨平台版本。
- NG-005：不首发插件商城、付费系统或广告平台。
- NG-006：不首发完整项目管理、笔记软件或邮件客户端。
- NG-007：不承诺读取所有主板、传感器、风扇和电压。
- NG-008：不默认保存独立于 Windows 剪贴板历史之外的完整剪贴板数据库。

## 5. 目标用户

### 5.1 主要用户

- Windows 11 桌面重度用户；
- 需要快速查看日程、待办、便签和剪贴板的知识工作者；
- 希望替代系统 Widgets 但不愿安装完整 Shell 修改工具的用户；
- 在意内存、CPU、联网行为和数据隐私的用户；
- 喜欢自定义布局，但不希望维护脚本和配置文件的用户。

### 5.2 次要用户

- 使用多显示器的开发者、设计师和内容创作者；
- 需要简单计时和系统监控的学生；
- 希望开发第三方数据卡片的开发者。

## 6. 支持范围与假设

- 首发目标：Windows 11 x64，当前仍受微软支持的客户端构建。
- 默认场景：系统任务栏位于屏幕底部。
- 精确替代左下角 Widgets 位置时，优先支持居中任务栏布局。
- 左对齐任务栏发生冲突时，使用用户可配置的安全位置或屏幕边缘按钮。
- ARM64、Windows 10、竖向任务栏和 Shell 修改工具兼容属于后续评估项。
- 用户通过系统设置手动关闭原生 Widgets；本应用只提供设置入口和说明，不修改组策略。

## 7. 核心用户旅程

### 7.1 首次使用

1. 用户安装并启动应用。
2. 应用解释其不会修改 Explorer，并提供“打开任务栏设置”。
3. 用户选择是否关闭系统 Widgets。
4. 用户选择按钮所在显示器和安全位置。
5. 应用展示默认卡片布局。
6. 用户可跳过账号和联网配置。
7. 用户完成引导后从任务栏按钮打开工作台。

### 7.2 日常快速查看

1. 用户按下任务栏按钮。
2. 按钮立即反馈。
3. 面板从按钮方向展开。
4. 用户查看天气、今日待办和下一日程。
5. 用户点击面板外区域或按 `Esc` 关闭。

### 7.3 快速记录

1. 用户打开面板。
2. 点击便签卡片输入区域。
3. 文本在本地自动保存。
4. 输入期间面板不会因临时失焦误关闭。
5. 用户关闭面板后，内容仍在下次打开时恢复。

### 7.4 编辑布局

1. 用户点击“编辑”。
2. 卡片显示拖动柄、尺寸和删除入口。
3. 用户拖动卡片，其他卡片连续让位。
4. 用户改变卡片尺寸。
5. 用户选择“完成”保存，或按 `Esc` 取消本次拖动。
6. 用户可撤销最近的布局操作。

### 7.5 使用剪贴板

1. 用户显式启用剪贴板卡片。
2. 卡片读取 Windows 剪贴板历史或当前内容。
3. 敏感内容默认缩略或遮罩。
4. 用户点击条目将其设为当前剪贴板内容。
5. 应用默认不把条目复制到自己的永久数据库。

## 8. 功能需求

### 8.1 系统与生命周期

#### SYS-001 单实例

应用的 LauncherHost、WorkspacePanel 和 CoreBroker 各自必须保持单实例。重复启动应激活现有实例或发送命令，不应创建重复任务栏按钮。

#### SYS-002 自动启动

用户可显式开启或关闭登录后启动。安装过程不得默认静默启用，除非安装界面清晰勾选且用户确认。

#### SYS-003 Explorer 恢复

Explorer 重启后，LauncherHost 应在 3 秒目标时间内重新定位按钮，不要求用户重启应用。

#### SYS-004 显示环境变化

应用必须响应：

- 显示器插拔；
- 分辨率变化；
- DPI 和缩放变化；
- 主显示器切换；
- 睡眠与恢复；
- 远程桌面连接与断开；
- 任务栏自动隐藏状态变化。

#### SYS-005 全屏处理

默认在独占或无边框全屏应用前隐藏任务栏按钮和面板。用户可为特定应用建立例外规则。

#### SYS-006 安全失败

当无法确认任务栏位置、窗口层级或显示器状态时，应用应隐藏入口并记录诊断，不得覆盖开始按钮、搜索、任务按钮或系统托盘。

### 8.2 任务栏入口

#### LCH-001 独立入口窗口

入口必须由应用独立拥有，不进入 Explorer 进程。稳定版不得使用 DLL 注入、XAML Diagnostics 或未公开任务栏元素。

#### LCH-002 位置

默认在主显示器任务栏左下角寻找安全区域。若目标区域被占用：

1. 尝试已保存的用户位置；
2. 尝试任务栏上方边缘位置；
3. 显示冲突提示并进入位置编辑；
4. 不得强行覆盖系统控件。

#### LCH-003 点击行为

- 左键按下立即显示按压反馈；
- 左键释放且指针仍在命中范围内时切换面板；
- 拖出命中范围后释放应取消；
- 不得默认在悬停时打开；
- 双击不得引入单击延迟。

#### LCH-004 命中测试

入口窗口中除按钮可交互区域外必须穿透鼠标。命中区域应提供最小 32×32 逻辑像素，并与视觉形状一致。

#### LCH-005 右键菜单

右键菜单至少包括：

- 打开/关闭面板；
- 编辑布局；
- 暂停后台刷新；
- 打开设置；
- 诊断；
- 退出。

#### LCH-006 状态表达

入口可使用克制徽标表达：

- 计时器完成；
- 待办逾期；
- 严重天气；
- 插件故障。

入口不得轮播新闻或持续闪烁。

#### LCH-007 快捷键

用户可配置全局快捷键。注册失败时应指出冲突并保持鼠标入口可用。不得默认劫持 `Win+W`。

### 8.3 工作台面板

#### PNL-001 面板窗口

面板为无任务栏按钮的独立顶层工具窗口，在普通窗口之上显示，但不得覆盖安全桌面、锁屏、UAC 或系统关键表面。

#### PNL-002 尺寸

默认尺寸遵循：

- 宽度为当前工作区 42%～48%；
- 最小宽度 680 逻辑像素；
- 最大宽度 960 逻辑像素；
- 高度为工作区 85%～94%；
- 与屏幕和任务栏保持 8～12 逻辑像素间距。

小屏环境允许接近全宽；超宽屏必须受最大宽度限制。

#### PNL-003 锚定

面板从入口按钮所在角向桌面方向展开。关闭时沿相同空间路径返回。多显示器时必须在触发入口所在显示器打开。

#### PNL-004 开关逻辑

- 点击入口切换显示；
- `Esc` 关闭最上层非模态内容，最终关闭面板；
- 单击面板外区域关闭；
- 编辑、拖拽、文本输入、文件选择器或授权窗口激活期间不得误关；
- 第二次触发必须从当前动画状态立即反向。

#### PNL-005 首帧与恢复

面板冷启动时可先显示缓存布局和骨架，但不得显示过期数据为实时值。数据必须带刷新状态。

#### PNL-006 标题区

标题区至少包含：

- 上下文问候或日期；
- 卡片搜索；
- 添加卡片；
- 编辑布局；
- 设置；
- 账号状态仅在用户启用同步后出现。

#### PNL-007 滚动

内容区域垂直滚动。标题区可保持可见，但不得使用永久硬分隔线；仅在发生内容重叠时显示滚动边缘效果。

#### PNL-008 固定模式

MVP 可不提供始终固定在桌面的模式。架构不得阻止未来增加“保持打开”或独立普通窗口模式。

### 8.4 卡片网格与编辑

#### LYT-001 响应式网格

默认使用四列逻辑网格，并根据有效宽度在两列、四列和六列之间切换。卡片通过列跨度和行跨度描述，不保存绝对屏幕像素。

#### LYT-002 标准尺寸

首版至少支持：

- S：1×1；
- M：2×1；
- L：2×2；
- W：4×1；
- XL：4×2。

卡片可声明支持的最小和最大尺寸。

#### LYT-003 编辑模式

正常模式禁止意外拖动。用户必须显式进入编辑模式，卡片才显示拖动柄、尺寸控制和移除入口。

#### LYT-004 拖动

- 卡片必须保持抓取偏移并 1:1 跟随指针；
- 移动超过约 8～10 逻辑像素后才进入拖动态；
- 捕获指针，移出卡片后仍连续跟随；
- 其他卡片实时预览让位结果；
- 释放后落到投影位置最近的合法网格；
- `Esc` 取消当前拖动。

#### LYT-005 冲突与紧凑

布局引擎必须保证无重叠、无越界。删除或移动卡片后应按稳定规则向上紧凑，不得随机改变无关卡片顺序。

#### LYT-006 撤销

编辑会话至少支持 20 步布局撤销/重做。退出编辑前发生崩溃时，恢复最后一次已提交布局。

#### LYT-007 多配置

首版只要求每个显示器一个布局。工作/专注/监控等多场景布局属于后续版本。

### 8.5 通用卡片行为

#### CRD-001 卡片状态

每张卡片必须支持以下状态中的适用集合：

- Loading；
- Ready；
- Empty；
- Stale；
- Offline；
- PermissionRequired；
- Unavailable；
- Error；
- Disabled。

不允许用数值 `0` 代替不可用。

#### CRD-002 更新信息

网络或传感器数据应显示最后更新时间或新鲜度。超出数据源定义的时效后进入 Stale。

#### CRD-003 可见性调度

卡片离开视口、面板关闭或显示器断开时，应暂停纯 UI 动画并降低或停止非必要轮询。

#### CRD-004 交互

卡片可提供：

- 主操作；
- 次要操作；
- 卡片内输入；
- 详情展开；
- 更多菜单；
- 设置。

卡片必须支持键盘操作，不能只依赖鼠标悬停。

#### CRD-005 错误隔离

单张卡片出错不得阻止其他卡片显示。卡片错误应提供重试、诊断和禁用入口。

### 8.6 内置卡片

#### WEA-001 天气

- 用户可手动选择城市或经纬度；
- 自动定位必须单独授权；
- 天气数据应缓存；
- 默认刷新周期不短于 15 分钟；
- 离线时显示最后成功数据及时间；
- 数据源和请求字段必须在隐私页说明。

#### NTE-001 快速便签

- 支持纯文本和基础 Markdown；
- 输入后自动保存；
- 保存失败时保留内存副本并明确告警；
- 支持撤销、搜索和复制；
- 不首发复杂知识库、双向链接或多人协作。

#### TMR-001 计时器

- 支持倒计时、暂停、恢复、取消；
- 面板关闭后继续计时；
- 应用重启后基于目标时间恢复，不依赖累计 tick；
- 完成时使用 Windows 通知；
- 可选专注计时预设。

#### TDO-001 本地待办

- 新增、编辑、完成、删除和排序；
- 支持截止日期、优先级和简单备注；
- 默认本地存储；
- 删除必须可撤销；
- Microsoft To Do 同步属于后续集成。

#### CLP-001 剪贴板

- 支持读取当前剪贴板；
- Windows 剪贴板历史启用时，可读取其历史；
- 支持文本、链接、图片和文件引用的安全预览；
- 默认不把历史永久复制到应用数据库；
- 支持一键暂停、清空视图和遮罩；
- 读取大图片或文件列表必须延迟且有大小上限；
- 插件不得自动获得剪贴板权限。

#### CAL-001 本地日历

- 提供月视图和近期日程摘要；
- 支持创建、编辑和删除本地事件；
- 支持全天事件、起止时间和提醒；
- 时区变化后正确重算显示；
- Outlook 和 Google 同步分别作为可选 Provider。

#### MON-001 系统监控

- 基础模式支持 CPU、内存、网络、磁盘和电池；
- 基础模式不要求管理员权限；
- 面板关闭时降低采样频率；
- 图表只在可见时渲染；
- 高级温度、风扇和电压通过可选 Provider 提供；
- 高级 Provider 不得让整个应用提权。

### 8.7 设置与管理

#### SET-001 设置入口

设置可从标题区、任务栏右键菜单和卡片菜单打开。设置窗口保持单实例。

#### SET-002 设置分类

至少包括：

- 常规；
- 任务栏入口；
- 外观与动效；
- 卡片；
- 账号与同步；
- 插件与权限；
- 隐私；
- 性能；
- 通知；
- 诊断与关于。

#### SET-003 实时预览

不会产生外部副作用的视觉设置应支持实时预览。取消时恢复原值。账号解绑、数据删除等操作不得用实时预览。

#### SET-004 导入导出

支持导出和导入：

- 布局；
- 非敏感设置；
- 本地便签、待办和日历数据。

默认不得导出账号令牌、剪贴板内容和插件密钥。

#### SET-005 重置

支持按模块重置，不得只提供“删除全部数据”。全量重置必须二次确认并生成可恢复备份。

### 8.8 插件

#### PLG-001 扩展边界

插件分为：

- 内置可信卡片；
- 外部数据 Provider；
- 外部声明式卡片。

MVP 不允许第三方插件向 WorkspacePanel 进程加载任意 XAML 或 DLL。

#### PLG-002 清单

插件必须声明：

- 唯一 ID；
- 名称、版本、作者；
- `apiVersion`；
- 入口点；
- 支持的卡片尺寸；
- 权限；
- 网络域名；
- 设置模式；
- 数据格式；
- 最低宿主版本。

#### PLG-003 权限

权限至少分为：

- `network`；
- `clipboard.read`；
- `clipboard.write`；
- `filesystem.read`；
- `filesystem.write`；
- `calendar.local`；
- `account.microsoft`；
- `hardware.basic`；
- `hardware.advanced`；
- `notifications`；
- `process.launch`。

宿主必须执行权限，不得只依赖插件自律。

#### PLG-004 隔离

外部插件在独立进程中运行，并受超时、消息大小、资源和崩溃策略约束。插件退出后宿主应显示错误占位并允许重启。

#### PLG-005 版本兼容

宿主拒绝未知主版本；允许兼容的小版本扩展字段；未知字段应在配置迁移中保留。

#### PLG-006 安装

第三方插件安装不属于 MVP 强制范围。首发若启用，只允许本地明确选择文件并展示权限，不提供静默远程安装。

### 8.9 通知

#### NTF-001 通知类型

支持：

- 计时器完成；
- 日程提醒；
- 待办到期；
- 严重天气；
- 插件持续故障。

#### NTF-002 克制

卡片普通刷新不得产生通知。所有通知类别可单独关闭。专注模式下遵循 Windows 通知策略。

### 8.10 数据与账号

#### DAT-001 本地数据

布局、便签、待办、本地日历、计时器和非敏感设置存储于用户本地。

#### DAT-002 密钥

OAuth 令牌和插件密钥必须存入 Windows Credential Manager 或使用 DPAPI 保护，不得以明文 JSON 存储。

#### DAT-003 云同步

云同步必须按 Provider 单独启用。断网时核心本地卡片仍可工作。冲突不得静默覆盖，需按数据类型定义合并策略。

#### DAT-004 遥测

首版默认不上传使用遥测。崩溃报告必须由用户主动发送，并在发送前展示包含的数据。

## 9. 非功能需求

### 9.1 性能

- NFR-PERF-001：面板关闭且使用默认卡片时，总后台工作集 P95 目标不超过 60MB。
- NFR-PERF-002：参考机器空闲 10 分钟平均 CPU 目标不超过 0.3%。
- NFR-PERF-003：面板关闭后不得持续等待 VSync。
- NFR-PERF-004：按下入口后 50ms 内必须出现视觉反馈。
- NFR-PERF-005：入口触发后 100ms 内出现面板首帧，300ms 内达到基础可交互。
- NFR-PERF-006：普通卡片滚动和拖动目标为显示器刷新率下无明显掉帧；验收使用帧时间而非主观描述。
- NFR-PERF-007：所有后台 Provider 必须集中调度，禁止每个卡片创建无协调的高频定时器。

### 9.2 可靠性

- NFR-REL-001：插件崩溃不能导致核心进程退出。
- NFR-REL-002：布局和用户内容写入必须具备原子性或事务。
- NFR-REL-003：数据库升级前生成备份，迁移失败可回退到只读恢复模式。
- NFR-REL-004：持续运行 24 小时不得出现无界内存增长。

### 9.3 安全

- NFR-SEC-001：IPC 只允许当前登录用户访问。
- NFR-SEC-002：消息必须做长度、版本、类型和值域校验。
- NFR-SEC-003：基础安装和运行不需要管理员权限。
- NFR-SEC-004：高级硬件访问若需要服务，服务接口必须只读、最小化并单独安装。
- NFR-SEC-005：更新包和正式发行包必须验证签名。

### 9.4 隐私

- NFR-PRI-001：无账号、无网络仍能使用便签、计时器、待办和本地日历。
- NFR-PRI-002：剪贴板内容默认不永久保存。
- NFR-PRI-003：每个联网 Provider 显示其域名、数据用途和最后访问时间。
- NFR-PRI-004：用户可按模块删除数据。

### 9.5 无障碍

- NFR-A11Y-001：完整键盘导航和清晰焦点样式。
- NFR-A11Y-002：UI Automation 提供名称、角色、状态和操作。
- NFR-A11Y-003：支持系统高对比度、文本缩放、减少动态效果和减少透明度。
- NFR-A11Y-004：颜色不是传达警告和状态的唯一方式。
- NFR-A11Y-005：常用点击目标至少 32×32 逻辑像素，首选 36×36 以上。

### 9.6 本地化

- NFR-I18N-001：首发至少支持简体中文和英语。
- NFR-I18N-002：所有用户文本使用资源文件，不硬编码。
- NFR-I18N-003：时间、日期、数字和单位遵循用户区域设置。
- NFR-I18N-004：布局允许文本增长 30% 而不截断关键操作。

## 11. MVP 验收场景

### AC-001 入口稳定性

在两个显示器、125% 与 150% DPI 环境下重启 Explorer，入口在 3 秒目标内恢复，且不覆盖系统按钮。

### AC-002 面板响应

冷启动与热启动分别记录从按下到首帧、到可交互的时间，达到 NFR-PERF-004/005。

### AC-003 拖动契约

从卡片非中心位置抓取并拖动，卡片保持抓取偏移；释放后无重叠；拖动期间点击不触发卡片主操作。

### AC-004 自动隐藏与全屏

任务栏自动隐藏时，入口不阻挡系统热区；全屏应用中默认不显示入口或面板。

### AC-005 数据恢复

在写入布局和便签时模拟进程终止，重启后恢复最后已提交状态，不出现损坏数据库。

### AC-006 剪贴板隐私

未启用卡片时不读取历史；启用后可暂停；退出应用后数据库中不存在剪贴板正文。

### AC-007 插件故障

模拟外部 Provider 超时、返回超大消息和崩溃，核心面板继续工作并显示隔离错误。

### AC-008 无障碍

仅使用键盘完成打开面板、切换卡片、添加待办、启动计时器和关闭面板。

### AC-009 性能

在记录的参考机器上完成 10 分钟空闲和 5 分钟面板使用 WPR/WPA 测量，并保存基线报告。

## 12. 成功指标

发布后仅在用户自愿参与统计时评估：

- 入口到面板成功打开率；
- 无崩溃会话比例；
- 用户保留的卡片数量；
- 面板打开响应分位数；
- 默认配置后台 CPU 与工作集；
- 插件故障不影响核心的隔离成功率；
- 用户关闭新闻流或账号的比例不作为负向指标。

## 13. 主要风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Windows 更新改变任务栏行为 | 入口错位或隐藏 | 使用公开窗口边界、失败关闭、构建矩阵 |
| WinUI 冷启动偏慢 | 面板感知延迟 | 缓存骨架、短时保温、减少启动依赖 |
| 卡片过多造成资源增长 | 违背轻量目标 | 可见性调度、统一计时器、虚拟化 |
| 剪贴板泄露 | 高隐私风险 | 默认不持久化、遮罩、显式权限 |
| 插件越权 | 数据或系统风险 | 独立进程、权限代理、IPC 校验 |
| 许可证污染 | 无法按预期分发 | 不复制受限源码、依赖审查、记录来源 |
| 云同步冲突 | 数据丢失 | 本地优先、版本戳、明确冲突策略 |
