# WinWidgetBoard 轻量产品需求

文档状态：已批准
版本：0.4
日期：2026-09-01
适用范围：轻量核心版

## 1. 产品定位

WinWidgetBoard 是一个 Windows 11 本地优先快捷工作台。用户通过独立任务栏按钮打开原生半屏面板，完成便签记录、天气查看、本机硬件与 AI 用量读数查看和少量布局调整。

产品不替换 Windows Shell，不注入 Explorer，也不发展成新闻平台、插件市场或完整个人信息管理套件。

## 2. 产品原则

1. **少而稳定**：功能数量服从启动速度、后台占用和可靠性。
2. **本地优先**：便签和布局不依赖账号或云服务。
3. **公开 API**：任务栏入口只使用公开 Win32 能力。
4. **用户掌控**：无默认遥测、广告或新闻流；自动定位使用 Windows 系统授权并可关闭。
5. **按需运行**：面板关闭后停止不可见动画；后台只保留有界、低频且可测量的必要工作，当前仅天气按小时刷新以供任务栏入口显示（[ADR-0024](adr/0024-background-provider-keepalive.md)）。
6. **直接实现**：不为延期功能提前建立平台级抽象。
7. **广泛适配**：作为开源工具，参考机只是验证环境，不是目标环境。每项能力在其他机器上必须要么可用，要么诚实降级为明确状态，不得显示 0、占位数字或覆盖系统控件；机器与用户差异（传感器、GPU、网卡、语言区域、单位制、任务栏形态、Windows 版本）由各能力显式声明适配边界。

| --- | --- | --- |

| 基础布局 | `LYT-001`～`LYT-007` | 响应式网格、编辑、拖动、增删、保存和已有撤销 |

| 天气 | `WEA-001`～`WEA-002` | 当前天气、Windows 自动位置、地点搜索、刷新状态和来源说明 |
| 硬件监控 | `MON-001`～`MON-003` | 本机读数、卡片与任务栏两处显示、显示项自定义 |

## 4. 功能需求

### 4.1 系统

#### SYS-001 单实例

LauncherHost、WorkspacePanel 和 CoreBroker 各自保持单实例。重复启动应激活或连接现有实例。

#### SYS-002 普通用户运行

安装和基础运行不得要求管理员权限。

#### SYS-003 安全失败

无法确认任务栏位置、IPC 状态或数据状态时，应隐藏、降级或显示明确错误，不得覆盖系统控件或伪造成功。

### 4.2 任务栏入口

#### LCH-001 独立窗口

入口由应用拥有的 Win32 窗口实现，不进入 `explorer.exe`。入口进程持有面板与 CoreBroker
的生命周期：入口结束（含被强制结束）时不留下孤儿进程（[ADR-0026](adr/0026-launcher-owned-process-tree.md)）。

#### LCH-002 安全位置

默认嵌入任务栏条带并显示可切换信息，对齐方式由用户选择；条带由显示器与工作区矩形推导。
开启硬件监控时入口为并排的两枚胶囊，对齐针对整体而非仅主胶囊。
系统图标左对齐、任务栏自动隐藏、垂直任务栏或条带过薄时，按用户配置降级为悬浮位置或隐藏，
不覆盖开始按钮等系统控件。Windows 11（build 22000）之前的任务栏在条带内排满窗口按钮、
几何无法看见，因此一律不嵌入条带，恒用工作区内的安全槽位（产品原则 7）。
详见 [ADR-0023](adr/0023-embedded-taskbar-entry-strip.md)。

#### LCH-003 点击

鼠标按下立即反馈，释放时提交；拖出命中范围后释放取消。悬停、按下与「面板已打开」三种状态
各自可辨，且不只依赖颜色区分；面板打开时入口的指示器与面板展开动效同步。

#### LCH-004 命中与穿透

只有入口自身形状（胶囊本体，不含外接矩形的圆角外侧）接收输入，其余区域穿透；
高度不小于 32 逻辑像素，宽度随内容在 96～280 逻辑像素间自适应。

#### LCH-005 长期可用

入口可作为普通程序安装到固定位置并随登录启动，不依赖仓库、开发脚本或包装进程；
安装仅限当前用户，且可完整卸载（`scripts/Install-WinWidgetBoard.ps1`）。

### 4.3 工作台面板

#### PNL-001 原生面板

使用独立 WinUI 3 顶层窗口，不显示普通任务栏按钮。

#### PNL-002 几何

面板保持在触发显示器工作区内，并受合理最小、最大宽度约束。

#### PNL-003 锚定开关

面板从入口方向展开，关闭沿相同路径返回；反向操作不得锁定输入。

#### PNL-004 关闭规则

入口切换、`Esc` 和面板外点击可以关闭；文本输入、拖动或模态对话框期间不得误关。
关闭表示隐藏窗口并保留进程，下一次打开不再付冷启动代价（[ADR-0025](adr/0025-resident-workspace-panel.md)）。

#### PNL-005 可恢复状态

Broker 不可用或数据加载失败时，面板仍能启动并显示可理解的不可用状态。

### 4.4 基础布局

#### LYT-001 响应式网格

按有效宽度使用 2/4/6 列逻辑网格，不保存绝对像素位置。

#### LYT-002 有限尺寸

继续支持现有 S/M/L/W/XL 离散尺寸，不新增自由像素布局。

#### LYT-003 显式编辑

普通模式禁止误拖；只有进入编辑模式后显示拖动和尺寸入口。

#### LYT-004 拖动

拖动保持抓取偏移、连续跟随、合法投影和 `Esc` 取消。

#### LYT-005 稳定排布

布局必须无重叠、无越界，并保持确定性。

#### LYT-006 保存

只在编辑完成时写入布局；保留现有 revision 保护和撤销能力，不继续扩展场景布局或复杂动效。

#### LYT-007 增删卡片

编辑模式下可以移除卡片，也可以把不在面板上的内置卡片添加回来。内置实例是单例，同一身份不能重复
添加；增删与移动、缩放共用同一条撤销历史，并在编辑完成时一并保存。这里不新增卡片类型。

### 4.5 本地便签

#### NTE-001 便签

- 本地创建、编辑、列表、搜索和删除；
- 纯文本与基础 Markdown；
- debounce 自动保存；
- 保存失败保留当前草稿并允许重试；
- revision 冲突不静默覆盖；
- 不发展成知识库、协作编辑或版本管理系统。

### 4.6 天气

#### WEA-001 天气

- 使用 Open-Meteo 获取当前天气；
- 首次正常打开面板时由 Windows 请求一次位置授权，允许后每次冷启动读取一次设备位置；
- 拒绝、关闭系统定位或无位置数据时保留当前手动位置；设置中可关闭自动定位；
- 可见时按低频计划刷新，不可见时暂停非必要请求；
- 网络失败时显示状态并保留当前进程内同位置的最近成功数据；
- 显示数据来源；
- 卡片按当前天气状况显示一张平面插画，用于一屏之内的快速辨认；
- 显示单位可在公制（°C、km/h）与英制（°F、mph）间选择，默认公制，随设置持久化（产品原则 7）；
- 当前不实现跨重启天气 payload 缓存。

#### WEA-002 位置设置

用户通过**搜索地名**设置位置，从候选列表中选择；经纬度由搜索结果提供并只读展示，不再手工输入。
同名地点由一级行政区与国家区分。搜索只在提交时发生，不做按键即搜；无匹配与搜索不可用是两种
不同的提示。落盘的仍然只有标签与经纬度（[ADR-0027](adr/0027-weather-location-search.md)）。

### 4.7 硬件监控

#### MON-001 本机读数

- 只读取本机硬件读数，不上报、不联网；
- 公开 API 层覆盖 CPU 占用与频率、内存、GPU 占用与显存、磁盘活动与占用、网络上下行；
- CPU 频率取当前最快的一颗核，由每核性能计数器测出，不需要驱动
  （[ADR-0031](adr/0031-cpu-clock-from-per-core-counters.md)）；
- 温度与风扇没有任何用户态 API，读数来自用户已在运行的监控程序的共享内存：
  HWiNFO 覆盖三项，Core Temp 只覆盖 CPU 温度。有源时显示真实读数，无源时该行**不显示**——
  一行常驻的安装指引属于设置页，硬件监控设置在指标列表旁说明来源要求；
  源在运行而这台机器确实没有该传感器时才显示「此电脑无法读取」；有没有源**逐项判断**
  （[ADR-0033](adr/0033-hwinfo-shared-memory-sensor-source.md)、
  [ADR-0034](adr/0034-core-temp-as-a-second-sensor-source.md)；
  本产品不分发、不加载、也不自行签发任何内核驱动，
  [ADR-0029](adr/0029-drop-the-bundled-sensor-driver.md)）；
- 任何读不到的项显示状态而非 0 或占位数字（[ADR-0028](adr/0028-system-monitor-scope-and-sensor-tiers.md)）；
- 采样按需进行：卡片可见或任务栏入口正在索要读数时才采样，两者皆无时休眠。

#### MON-002 两处显示

- 卡片逐行显示读数，有明确上限的读数附一条进度条，速率类不附；
- 任务栏侧是**主入口胶囊右侧的一枚独立胶囊**，可与日期时间或天气同时存在，在面板设置的「任务栏入口」分类里单独开关；
  读数在其中分两行密排，彼此以细线分隔；
- 每个读数画在自身最近两分钟的历史走势之上；有上限的指标按自身上限绘制，速率按窗口峰值相对绘制，
  读不到的指标不画图；
- 入口不显示任何需要翻译的文字：短标签在两种语言下写法相同，网络方向由图形表达；
- 装不下的读数在入口上整列省略，不半截截断；条带放不下两枚胶囊时先丢硬件胶囊，入口本身始终可达。

#### MON-003 显示项自定义

- 卡片与任务栏**各自独立**配置，每处最多 8 项；
- 可自定义显示哪些项、顺序，以及每项的详细度（仅数值 / 数值与进度条 / 完整信息）；
- 设置经版本化本地 IPC 保存，冲突时报 `conflict.sysmon-settings-revision`。

### 4.8 Token 用量

#### USE-001～USE-013 本机用量读数

详细结论与门禁见 [ADR-0030](adr/0030-token-usage-card.md)，要点：

- 只读取各工具在本机写下的会话记录（当前 Claude 与 Codex），不接任何计费 API、不联网；
- 消息正文不构造字符串、不进内存；聚合结果不落盘，落盘的只有厂商启用设置；
- 分总览页与厂商页，以当日花费为主视觉，金额按公开 API 价折算并标 `≈`，
  无价模型不计入并标为下限；24 小时趋势；内容按卡片格数披露；
- 不展示订阅配额推算；配额只按厂商自己记录的数值原样显示；
- 卡片不可见时完全不读盘；新增厂商需经同一 ADR 的门禁。

### 4.9 最小设置

#### SET-001 设置入口

当前只要求天气位置及与核心能力直接相关的少量设置。取消不得产生外部副作用。

## 5. 非功能要求

### 5.1 性能

- 面板关闭后不持续等待 VSync；
- 不可见卡片停止纯 UI 动画；
- Provider 使用现有集中调度，不创建每卡永久定时器；
- 启动和后台占用以实际 Release 测量为准；
- 60 MB 后台工作集和 300 ms 可交互仍是方向目标，但只在发布候选阶段作为正式门禁。

### 5.2 可靠性

- 用户内容写入使用事务或 revision 保护；
- IPC 断开可以重连；
- 单卡或天气失败不阻止便签和布局使用；
- 不允许无界队列、无限重试或无限日志。

### 5.3 安全与隐私

- IPC 只允许当前用户；
- 会话令牌不得写日志；
- 便签正文不得进入诊断日志；
- 天气请求只发送 Windows 定位或用户选择的位置及必要字段；
- 默认无账号和遥测；位置权限和开关由用户掌控。

### 5.4 无障碍

核心流程需要键盘可达、明确焦点、UIA 名称、减少动态效果和高对比度基础支持。完整设备与偏好矩阵仅在发布候选阶段执行。

## 6. 核心验收

日常开发只维护以下核心旅程：

1. 入口点击可以打开和关闭面板；
2. 面板在一个明确的 Windows 11 x64 参考环境中正确显示；
3. 四卡布局可拖动、保存并在重启后恢复；
4. 便签可创建、保存、搜索、打开和删除；
5. 天气可加载，位置可修改并在 Broker 重启后恢复；
6. 硬件读数与 Token 用量卡片可显示读数，显示项与厂商设置可保存并在重启后恢复；
7. 验收实例和数据库与生产数据隔离。

多显示器、完整 DPI、高对比度、屏幕阅读器、性能、长稳、安装和签名矩阵属于发布候选验证，不再阻塞每个功能提交。

## 7. 延期范围

以下内容不在当前路线中：

- 计时器业务；
- 本地待办；
- 剪贴板卡片；
- 本地或云日历；
- Outlook、Google、Microsoft To Do；
- 第三方插件、PluginHost、插件 SDK 和市场；
- 云同步、账号、遥测平台；
- 多套布局、自由像素布局；
- 企业级安装、更新通道和管理策略。

重新启用任何延期范围前，必须由用户明确选择，并先评估对体积、后台资源和维护成本的影响。

## 8. 成功标准

轻量核心版成功不以功能数量衡量，而以以下结果衡量：

- 七项核心能力日常可用；
- 启动和后台占用保持克制；
- 代码可以由少量维护者理解和修改；
- 普通改动不需要跨越大量无关文件；
- 项目目录不长期积累可重建输出；
- 用户数据和隐私边界保持可靠。
