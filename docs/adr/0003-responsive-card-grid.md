# ADR-0003：卡片使用确定性响应式网格

状态：Accepted
日期：2026-08-06

## 背景

用户要求“自由堆放卡片”。候选：

1. 任意像素坐标；
2. Masonry 自动瀑布流；
3. 固定磁贴尺寸；
4. 响应式列网格＋离散跨度。

任意像素在 DPI、分辨率和面板宽度变化后容易失效。纯 Masonry 难以保持用户预期位置。

## 决策

采用 2/4/6 列响应式网格，卡片声明离散尺寸：

- S 1×1；
- M 2×1；
- L 2×2；
- W 4×1；
- XL 4×2。

持久化顺序、跨度和可选 preferred column。运行时使用确定性的 top-left first-fit compacting 计算位置。

## 理由

- 可自由编排但不会失控；
- DPI 和宽度变化可重排；
- 无重叠；
- 易于键盘操作；
- 易于属性测试；
- 插件可声明尺寸；
- 布局数据稳定。

## 后果

正面：

- 可预测；
- 易恢复；
- 适合虚拟化；
- 易撤销。

负面：

- 不能精确摆放到任意像素；
- 跨列变化可能改变视觉位置；
- 需要设计稳定紧凑规则。

## 交互约束

- 正常模式不拖动；
- 编辑模式才显示拖动柄；
- 1:1 跟随并保持抓取偏移；
- 拖动阈值 8～10 逻辑像素；
- `Esc` 取消；
- 其他卡片实时让位；
- 不在每帧持久化。

## 验证

- 属性测试 NoOverlap/WithinBounds/Deterministic；
- 100 卡片；
- 2/4/6 列 round trip；
- 随机 add/remove/move/resize；
- 真实鼠标和键盘。
