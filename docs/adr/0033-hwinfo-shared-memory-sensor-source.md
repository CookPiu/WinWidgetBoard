# ADR-0033：温度与风扇改由 HWiNFO 共享内存读取

状态：Accepted
日期：2026-09-01
关系：取代 [ADR-0029](0029-drop-the-bundled-sensor-driver.md) 第 3 条中「温度与风扇恒为不可读」的结论；
ADR-0029 第 1、2 条（不实现 `src/SensorHost`、不分发任何 WinRing0 系驱动）**继续有效，且正是本决定成立的前提**

## 背景

[ADR-0029](0029-drop-the-bundled-sensor-driver.md) 验证了驱动路线在参考机上走不通，
并在同一份决定里否掉了共享内存路线，理由写得很清楚：HWiNFO 的共享内存确实含 CPU 温度，
但「要求用户安装并常驻 HWiNFO——那只是把常驻一个第三方监控软件换成常驻另一个，
用户已就此选择放弃」。

用户现要求使用 HWiNFO。该理由的前提随之失效：常驻与否是用户自己的选择，
本产品需要做的只是**在他已经运行时读到，在他没有运行时说清楚**。
被 ADR-0029 否掉的另外两条路线（分发驱动、自建提权助手）不受影响，本决定不碰它们。

## 决策

1. **CoreBroker 只读打开 `Global\HWiNFO_SENS_SM2`**，按 HWiNFO 的 SM2 布局解析，
   取 CPU 温度、GPU 温度、风扇转速三项——正是此前恒为不可读的三项。不新增指标标记。
2. **不安装、不启动、不提权、不写入**：只有 `OpenExisting` 加一个只读视图。
   HWiNFO 不在就静默放弃，每 5 秒重探一次；这条路径在绝大多数机器上每一拍都会走到，
   因此必须无异常、无日志、无残留。
3. **只认全局命名空间，不做本地名回退。** 会话本地命名空间任何进程都能创建，
   回退等于给同会话的任意进程一个喂假读数的入口；全局命名空间需要 `SeCreateGlobalPrivilege`。
4. **该块按不可信输入对待**：签名、版本、两段各自的偏移／元素大小／元素个数逐项按映射长度校验，
   越界与溢出用 64 位运算挡住，任何一项不符即整体降级为「没有传感器源」，不做部分解析。
   只接受本代码实现的那一个布局版本，未知版本不重新解释。
5. **新增指标状态 `needs-sensor-source`**，文案「需运行 HWiNFO」，与「此电脑无法读取」区分开：
   前者用户可以动手解决，后者是这台机器的事实。只有上述三项能取这个状态。
6. **选取策略是固定优先级表加传感器名兜底**：HWiNFO 的读数 ID 跨机器跨版本都不稳定，
   只能按类型、标签和所属传感器名判断。一台机器通常同时发布好几个「像是 CPU 温度」的读数
   （厂商 die 传感器、逐核最大值、主板对插槽的读数），按出现顺序取会在每台机器上选中不同的东西；
   `Distance to TjMAX` 这类以摄氏度为单位的**余量**读数一并排除，否则越热显示的数字越小。
7. **以 HWiNFO 自己的 poll 时钟判活**：我们持有句柄，所以 HWiNFO 崩溃后共享段不会消失，
   最后一次读数会永远停在那里冒充实时值。poll 时钟 60 秒不前进即断开，
   重探时若 HWiNFO 已重启则自动接上。

## 理由

**为什么不做设置开关。** 有就用、没有就说明白，是这个产品对机器差异一贯的处理方式
（[产品原则 7](../01-product-requirements.md)）。一个默认开启的开关只会多一处让读数消失的地方。

**为什么不取 HWiNFO 的互斥体。** SM2 提供 `Global\HWiNFO_SM2_MUTEX` 供读方同步，
但为一拍读三个 `double` 去抢另一个进程的内核对象，代价是被对方的写入节奏阻塞，
以及对方崩溃时的 `AbandonedMutex`。撕裂读的后果只是某一拍出现一个不合理的数字，
而量程校验本来就会挡掉它，下一拍即恢复。

**为什么不枚举 HWiNFO 进程判活。** 每拍一次进程枚举比读三个 `double` 贵得多，
而且进程还在不等于它还在写；poll 时钟直接回答的就是「它还在写吗」。

## 后果

- 进程数保持三个，锁文件里仍然只有微软与测试框架包，[ADR-0002](0002-split-process-architecture.md)
  与 [ADR-0022](0022-lightweight-core-strategy.md) 未被打破；无提权路径，`SYS-002` 不受影响；
- 这是本产品第一次读取**另一个进程发布的数据**（只读、本机、用户自己安装的），
  攻击面相应变化已记入 [docs/09](../09-security-privacy.md)；
- HWiNFO 免费版的共享内存有 **12 小时**限制，到期自动关闭且需手动重新勾选，
  这是 HWiNFO 的授权政策，本产品对此的表现就是回到「需运行 HWiNFO」；
- 参考机没有安装 HWiNFO，**真实块的解析尚未在真机上验证**：布局与 HWiNFO 公开 SDK 的结构一致，
  单元测试跑的是测试自己写出的合成块，缺席路径已在真机验证。这条在装上 HWiNFO 之前不要当作已验证；
- 若将来某项读数在不引入任何依赖的前提下可读（如独立显卡经厂商 API 取 GPU 温度），
  那是一个独立的、更小的决定，不需要推翻本 ADR。
