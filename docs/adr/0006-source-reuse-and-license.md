# ADR-0006：许可证未确定前只参考行为并重新实现

状态：Accepted
日期：2026-08-06

## 背景

参考项目包含 MIT、MIT 变体、GPL-2.0、GPL-3.0、AGPL-3.0、MPL-2.0、Anti-996 等多种条款。项目自身许可证尚未确定。

直接拼接源码可能导致分发义务冲突或无法采用预期许可证。

## 决策

当前阶段：

- 不复制参考项目源码；
- 只记录公开架构和行为；
- 自行重新实现；
- 不使用来源项目资源；
- 引入依赖逐项审查；
- 项目许可证由用户后续决定。

代码复用必须单独批准并记录精确 commit、文件、许可证和义务。

## 理由

- 保持许可证选择空间；
- 降低来源混淆；
- 避免 GPL/AGPL/Anti-996 污染；
- 方便未来商业或开源分发选择。

## 后果

正面：

- 来源清晰；
- 法律风险更低；
- 架构不被历史代码绑定。

负面：

- 需要重新实现更多基础设施；
- 短期开发速度较慢；
- 即使行为相似也需要独立测试。

## 后续

正式发布前必须：

- 决定项目许可证；
- 生成依赖清单和第三方 Notice；
- 审查图标、字体、示例数据；
- 审查 LibreHardwareMonitor 等可选组件；
- 建立 SBOM。
